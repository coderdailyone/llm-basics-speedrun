## 5.1 图像的本质:一张巨大的数字表格

对计算机来说,一张 1920×1080 的彩图 = **宽×高×3 的数值张量**(RGB 三通道,每值 0~255)。所谓"看图",就是在这 600 多万个数字里找规律。

| 物理现象 | 计算机视角 |
|---|---|
| 图像模糊 | 相邻像素值变得平滑 |
| 边缘轮廓 | 数值的剧烈跳变 |
| 颜色 | 三通道的配比(R 大 B 小=暖色) |
| 亮度 | 整体数值水位 |

💡 这解释了 CV 的若干直觉:**图像任务对旋转/平移敏感**(矩阵整体变了)、**数据增强有效**(翻转裁剪后仍是同物体)、**对抗样本存在**(人眼无异的微小扰动能让分类器崩溃——因为机器看的本来就是数字不是语义)。

## 5.2 卷积:CV 世界的乘法口诀

**操作定义**:拿一个小核(kernel,如 3×3),盖住图像一角,对应位置相乘再求和,输出一个数;滑遍全图,得到特征图(feature map)。

```
图像块          卷积核           输出
1 0 2          1 0 1
3 1 4    ×     0 1 0     =    1×1+0×0+2×1 + 3×0+1×1+4×0 + ... = 求和得单值
5 6 0          1 0 1
```

滑动的三个超参:
| 超参 | 含义 | 影响 |
|---|---|---|
| Stride 步幅 | 核每次挪几格 | 大步长 → 特征图更小更快 |
| Padding 填充 | 图边缘补零圈 | 保持尺寸不缩;边缘信息不被忽略 |
| Kernel size | 核大小 | VGG 之后业界统一用 3×3 叠深(两层 3×3 感受野等于一层 5×5,还多了次非线性) |

⭐ **两个先验是 CNN 成功的全部秘密**(呼应第一章母题三):
1. **局部性**:核只看小窗口——因为图像语义本来就局部性强(眼睛就是一小片);
2. **参数共享**:同一核扫全图——猫出现在哪都是猫(平移不变性)。

后果:参数量爆炸式下降。1000×1000 图接全连接要 10⁹ 参数,卷积只要几十个。

**堆叠出层次**:Conv+激活+Pooling(降采样取最大值)反复叠,特征图逐层变小、通道逐层变多、语义逐层抽象:

```
第1~3层   : 边缘 / 角点 / 简单纹理(横线竖线斜线)
第4~7层   : 纹理组合 / 局部部件(圆弧、车轮的一部分)
第8+层    : 物体级概念(脸、轮子整体)
```

(Zeiler 可视化经典结论:**这是一个自动学习的金字塔**,不需要人工告诉它该学什么。)

## 5.3 CNN 极简史:一部"越深越好,但深不动"的攻关史

| 网络 | 年份 | 关键贡献 |
|---|---|---|
| LeNet | 1998 | 手写数字识别雏形(先行者生不逢时) |
| **AlexNet** | 2012 | **引爆深度学习革命**:ReLU+GPU+Dropout 三件套,ImageNet 错误率从 26% 干到 15% |
| VGG | 2014 | 全部用 3×3 小核叠深度,结构极简美学 |
| GoogLeNet | 2014 | Inception 多尺度并行分支 |
| **ResNet** | 2015 | ⭐ **残差连接救了深度学习**:此后所有大模型的骨架 |

**ResNet 为什么值得单独讲?** 更深的网络本应更强,但实测层数加到 50+ 后训练误差反而回升(**退化问题**,且不是过拟合—— train 也变差)。何恺明的洞察:与其让深层网络学完整变换 H(x),不如让它只学"修正量":

$$y = F(x) + x \quad \text{(跳跃连接/捷径)}$$

网络只需学 F(x)≈0 的恒等映射即可保证不比浅层差。梯度沿 x 直通捷径回传,**梯度消失被物理性地绕开**——千层网络成为可能。

⚠️ 划重点:第四章 Transformer 里的残差连接(⊕号)正是 ResNet 思想移植。可以说:**没有残差连接就没有 GPT**。

## 5.4 任务阶梯:分类 → 检测 → 分割

| 任务 | 输出 | 代表算法 | 度量 |
|---|---|---|---|
| 分类 Classification | "这是猫"(单一标签) | ResNet/EfficientNet/ViT | Top-1/Top-5 准确率 |
| 检测 Detection | 猫在哪(框)+ 是什么 | Faster R-CNN(两阶段,准而慢)/ YOLO 家族(单阶段,快而糙)/ DETR(Transformer 直接集合预测) | mAP(不同 IoU 阈值下精度的综合) |
| 分割 Segmentation | 每个**像素**的类别(语义分割)/每个实例分开(实例分割)/合体(全景分割) | U-Net(Medical 明星)/Mask R-CNN/**SAM**(Segment Anything 万物可分) | IoU(预测框/掩码与真值的交并比) |

检测的发展主线一句话:**两阶段(先提候选框再精修)→ 一阶段端到端回归 → anchor-free 化 → Transformer 化(DETR 把检测变成集合匹配问题)**。

**SAM(2023 Meta)提示一下新范式**:输入点/框作为提示,瞬间抠出任意物体掩码——从"针对预定义类别的判别器"进化为"可交互引导的基础模型",CV 也有了自己的"GPT 时刻"。

## 5.5 Vision Transformer:当图像遇见注意力

ViT(2020 Google)核心想法简单粗暴:
1. 图片切成固定小块 patch(如 16×16 像素);
2. 每个 patch 展平+线性投影 = 一个 token;
3. 加位置编码(哪个 patch 在哪)、拼上分类专用 [CLS] token;
4. **整包丢给标准 Transformer encoder**(和 LLM 同款);
5. 取 [CLS] 输出做分类。

> 论文副标题已是一切:"An Image is Worth 16×16 Words"(一图值十六词)。

**CNN vs ViT**(面试高频对比):

| 维度 | CNN | ViT |
|---|---|---|
| 先验 | 强(局部性+平移不变写死在结构里) | 弱(全局注意力,一切靠学) |
| 小数据集 | 稳赢(先验兜底) | 容易翻车(需要更多数据) |
| 超大数据/规模上限 | 早饱和 | 持续涨(ViT-L/H 吊打 CNN) |
| 距离建模 | 浅层看不见远处,需层层堆 | 一步到位全局关注 |

又一次验证第一章母题:**先验弱的架构在小数据吃亏、在大数据时代通吃**(与 decoder-only 的胜出完全同构!)。

**CLIP(2021 OpenAI):图文桥梁**
- 用 4 亿网络图文对做对比学习:配对的图文向量拉近,错配的推远;
- 学到的是联合对齐空间,从此"文字"和"图片"说同一门向量语言;
- 立竿见影三件套:**zero-shot 分类**(prompt 一句"a photo of a cat"就能分类任意新类别)、图文检索、以及——**为扩散模型提供文本条件**(下一节主角)。

## 5.6 Diffusion:扩散模型是怎么凭空画图的

GAN(2014)曾是生成霸主(真假鉴别器互相博弈),但训练不稳、模式坍塌。2020 起 **Diffusion 统一天下**,原理朴素到感人:

### 两阶段设定

```
前向(训练时): 把真图逐步加噪 T 步 → 直到纯噪声雪花 (规律已知)
反向(要学会): 从雪花出发,一步步减噪 → 还原成清晰图像 (这是要学的技巧)
```

训练:随机挑时间步 t、把真图加到相应噪度,让 U-Net/DiT 预测**这一步添加的噪声是什么**(本质是训练一个超级去噪器)。
生成:从纯噪声开始,调用去噪器走 T 步反向过程,图像如显影般浮现。

💡 **直觉类比:雕塑家的渐进显影**——大理石块(纯噪声)中"藏"着大卫像;雕刻家每一次敲击(U-Net 的去噪一步)都在去除多余部分。低分辨率草稿→细节完稿的创作流程与之同构。

### Stable Diffusion 三大件(工业标准架构)

```
文生图全流程:
Prompt "戴珍珠耳环的少女风格宇航员"
  → ①CLIP Text Encoder 编码成语义向量组(条件)
  → ②潜空间中随机初始化 latent 噪声
  → ③UNet(DiT)迭代去噪 N 步,每步注入①的条件:
        Classifier-Free Guidance (CFG):有条件/无条件两次预测,拉大差异
        以增强文本控制力("对齐你的文字意图")
  → ④VAE Decoder 从潜空间解码回像素图 ✓
```

三大件分工记牢:**CLIP 管"听懂话"、UNet 管"会画画"、VAE 管"省算力压缩/还原"**(在高维像素空间直接去噪太贵,压到 1/8 尺寸潜空间干活)。

现代演化:UNet → **DiT(Diffusion Transformer)**,与 Sora/Lumina 一脉相承;"统一理解+生成"是前沿方向;视频生成=增加时间维度的一致性约束([[06-多模态大模型与具身智能]] 展开);ControlNet 加几何条件(姿势/深度图/边缘草图)精准控图;LoRA 微调画风为开源生态最热玩法(与 LLM LoRA 同名同理!)。

## 5.7 OCR 与典型应用场景

**OCR 文字识别**两段式(检测文本行+识别字符)仍主导文档级高精度需求;通用 VLM(见下章)直接"看图说话"读字也在很多场景替代了传统管道,但版面复杂/超高精度仍以专业管线为稳。

| 场景 | 用到的技术栈 | 备注 |
|---|---|---|
| 工业质检 | 分类+检测+异常检测 | 小缺陷样本稀缺→迁移学习+合成缺陷 |
| 自动驾驶 | 检测/分割/BEV 感知/占据栅格 | 安全冗余要求极致,多传感器融合 |
| 医疗影像 | 分割+分类(Dr.CNN 读片) | 数据隐私+假阴性代价极高,辅助定位非确诊 |
| 遥感/农业 | 分割+变化检测 | 尺度大、目标小、云层干扰 |
| AR/三维 | SLAM/NeRF/3DGS | 从 2D 走向空间智能 |
