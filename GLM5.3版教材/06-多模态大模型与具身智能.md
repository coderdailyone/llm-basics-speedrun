## 6.1 为什么必须多模态

- **信息带宽**:人类输入的 80%+ 走视觉;纯文本丢掉了图表、表情、空间关系一整个世界;
- **任务刚需**:看化验单答诊断题、读 UI 截图写前端、"这张图哪里有 P 图痕迹"——文本-only 根本无法开始;
- **数据天花板**:高质量公开文本见底(第一章三要素预警),图像视频音频是下一个十倍量级的训练矿;
- **通往 AGI 的必经之路**:真正的通用智能必须能感知世界、在物理世界中行动(后半句就是本章下半场的具身智能)。

⚠️ 但注意"模态不是白来的":每种模态有自己的对齐难题——图文要对齐"哪个词对应哪个区域",语音要处理时间连续性,视频还要加一层跨帧一致性。

## 6.2 VLM 标准三段式架构(面试手画图)

```
                        ┌──────────────────────────┐
用户提问:"图里几个人?" ──→│                          │
                        │   LLM 底座(Qwen/Vicuna…) ├─→ 文本回答
图片 ─→ 视觉编码器 ─→ 对齐接口 ──→│      (主力参数都在这)     │
 (ViT/CLIP)  (投影层)        │                          │
                        └──────────────────────────┘
        ①看懂            ②翻译成"外语"    ③推理并作答
```

三个组件各司其职:

| 组件 | 干什么 | 主流选型 |
|---|---|---|
| **① 视觉编码器** | 图像 → 一堆特征向量(patch token) | 预训练 ViT / CLIP 视觉塔(为什么?因为它已经见过亿级图文,自带语义) |
| **② 接口模块(关键!)** | 把视觉向量"翻译"成 LLM 认识的 token 序列 | 见下方三代方案 |
| **③ LLM 底座** | 拼接视觉 token + 文本 token,统一自回归生成 | 冻结或 LoRA 微调的开源 LLM |

### 接口模块的三代演进(⭐核心考点)

| 方案 | 做法 | 代表 | 优劣 |
|---|---|---|---|
| 线性投影 | 一个小 MLP 直接把 patch 向量投到 LLM 维度 | **LLaVA**(2023,学术网红) | 极简可复现;粗糙但便宜好用 |
| Q-Former 查询桥 | 少量可学习查询向量通过交叉注意力向视觉特征"抓取"信息,输出固定数量 token | **BLIP-2** | 大幅压缩视觉 token 数(32 个搞定一张图);结构复杂难训 |
| Cross-Attention 注入 | 不拼接进序列,LLM 内部设交叉注意力层直接从视觉特征取信息 | Flamingo | 灵活支持多图穿插文本 |
| 原生多模态 | 预训练阶段从头就是全模态统一 token 流,无后补接口 | GPT-4o 类 / Chameleon | 体验最自然;预训练成本巨大 |

## 6.3 一次完整的多模态调用(流程走读)

以"上传一张晚餐照片问:这顿多少卡路里?"为例:

```
1. 图片 → 预处理(resize 到适配分辨率,动态分辨率如 Qwen-VL 按需切块保细节)
2. → ViT 编码 → N 个视觉 token(比如几百个)
3. 文本提示 "这张晚餐的照片里大约有多少卡路里?" tokenize 成 M 个 token
4. 序列拼接:[视觉token ×N][文本token ×M] 送入 LLM —— 在模型眼里全部都是 token!
5. 自回归生成:"这是一份汉堡套餐…估算约 850 千卡"(底层是逐 token 预测)
```

⚠️ 注意第 4 步:**LLM 本身一行代码都没改**,它只是被喂了会读图的"前置翻译"。这就是"接口比大脑便宜"的经典工程哲学,也是开源 VLM 能一个月内遍地开花的原因。

**代表性能力清单**(现代旗舰 VLM):细粒度 OCR(票据/手写)、图表解读推理、GUI Agent 看屏操作、多图时序理解、视频理解与时位定位。

## 6.4 输出侧三大件:画图、做视频、配音色

| 方向 | 代表技术 | 一句话现状 |
|---|---|---|
| 文生图 | Stable Diffusion/DiT(第五章已拆)/ControlNet 条件控制/LoRA 画风 | 工业级成熟,商用版权合规是主要门槛 |
| 文生视频 | Sora(DiT+时空 patches)/Kling/Runway/国内可灵海螺 | 15~60 秒高一致性可用;物理规律偶尔"露馅"(玻璃不碎反融);算力成本极高 |
| 统一理解+生成 | Chameleon/JSD/Janus 系 | 上升期:一个模型既懂又画,还偶有"文字渲染之谜"待解 |
| 语音 ASR | Whisper(encoder-decoder 直接端到端) | 多语种鲁棒,开源界地基 |
| 语音 TTS | VALL-E/XTTS(3 秒克隆音色)/GPT-SoVITS 开源生态 | 已到真假难辨;情感韵律还在进步 |
| 数字人 | 语音驱动口型(LivePortrait/SadTalker)+形象驱动+实时流 | 直播数字人已商用;实时性与拟真度仍是价格敏感区 |

💡 观察:**所有模态最终都被 Transformer 化了**(ViT 处理像素、Whisper 处理频谱、DiT 处理时空块)。Transformers 之于 AI,就像 CRUD 之于 Web 后端——先学它,再谈创新。

## 6.5 下半场:具身智能 Embodied AI

### 从"缸中之脑"到"有身体的智能"

前五章的模型都活在数字世界(柏拉图的洞穴):看过一万张火苗图片,**却从未被烫过一次**。具身智能主张:真智能需要身体——通过感知-行动闭环与世界交互来学习("认知根植于身体",机器人学说的 Embodiment)。

**Moravec 悖论(本半场总纲)**:

> 让 AI 下象棋赢世界冠军容易,让它像 5 岁孩子一样灵活地叠一件衬衫极难。
> **高阶推理是演化晚近的薄涂层,感知运动才是演化打磨了几亿年的深冰山。**

### 三条技术路线(当前格局)

**路线 A:VLA(Vision-Language-Action)模型**
把"感知-决策"两步压进一个大模型:视觉+语言指令进去,**直接输出动作 token**(机械臂关节角度序列)。

```
图像 + 指令"把桌上的杯子放进水槽"
  → VLA 大模型(RT-2/Pi0/OpenVLA/RDT 系列)
  → 动作 tokens → 机械臂控制器执行 → 新观察 → 循环
```

= 第五章 CLIP + 第四章 LLM 的动作版续集:**互联网级知识第一次被搬进了机器人的手**("看到banana黄色→知道是食物→知道轻拿轻放",这些常识来自语言预训练而非机器人专属训练)。

**路线 B:世界模型(World Model)**
让模型内化一个可模拟的物理环境引擎:给它状态和动作,它能预测下一帧会发生什么(Sora 已展示隐式世界模型的雏形;Dreamer 类在想象中练习 RL)。口号:**在梦里学会骑车,再骑真车**——样本效率远高于真实试错。争议:视频预测是否等于真正理解因果物理?

**路线 C:模仿学习 + 强化学习**
- 模仿学习 Imitation Learning:人类遥操作示范(teleoperation,经典 ALOHA 双臂系统)**录成轨迹数据集**,策略网络学着复现(diffusion policy 是当前爆款:把动作生成当扩散去噪);
- 强化学习:仿真环境中海量试错(Isaac Gym 并行数万机器人),再迁移真机;
- 未来理想态:**遥操作造种子数据 → 仿真扩展规模 → 真机微调落地** 的数据飞轮。

### Sim2Real:仿真学的技能能带到现实吗

仿真(U/Isaac)可以一天跑出一万年的经验,但"仿真 vs 现实"永远有 gap(摩擦/光照/动力学微差)。主流缓解:**域随机化 Domain Randomization**——训练时刻意随机打乱颜色/材质/摩擦力,"既然见过的世界千奇百怪,现实这点波动也算不了什么"。(这个思路本身就很有哲学味:**主动注入噪声换取鲁棒性**。)

### 数据困境:具身智能最大的瓶颈

| 模态 | 数据来源 | 体量 |
|---|---|---|
| 文本 | 整个人类互联网 | 百万亿 token |
| 图像 | 亿级 Flickr/相册 | 数十亿张 |
| 视频 | YouTube 级平台 | PB 级 |
| **机器人轨迹** | ??? 要么真人穿设备采集($$$),要么仿真合成(gap) | **稀缺一个数量级以上** |

互联网里没有"怎么洗碗"的第一人称动作记录——这就是具身数据的基本困局,也是各家狂卷遥操作工厂/仿真平台的原因。谁的飞轮先转起来,谁就有下一代"GPT 时刻"的门票。硬件侧,人形机器人(Optimus/Unitree/Figure 国内外梯队)与灵巧手是载体竞争焦点;模型侧,VLA + 世界模型的融合是最被看好的收敛方向。
