## 3.1 语言为什么是 AI 最硬的骨头

结构化数据(表格)里全是明确字段;而自然语言有三个先天坑:

**① 歧义(同形不同义)**

| 层级 | 例子 |
|---|---|
| 分词歧义 | "南京市长江大桥" = 南京市 / 长江大桥 或 南京市长 / 江大桥 |
| 词义歧义 | "苹果很好吃" vs "苹果发新机了"(apple 两个完全不同的意思) |
| 句法歧义 | "咬死了猎人的狗"(谁咬谁?) |
| 指代歧义 | 小明把书还给小刚,**他**才安心(他是谁?) |

**② 无限创造性**:语法有限、句子无限。"把紫色的梦想煮成一分钟"从没人在现实说过,你却觉得它通顺——因为人类有组合式语法。模型必须学会这种**系统性组合能力**,而不是背句子。

**③ 常识依赖**:"仓库里的纸箱太小装不下球"——请问球露出多少?没有常识就寸步难行。

## 3.2 文本表示进化史(本章主线)

计算机只认数字,"语言→数学"的第一步决定了一切。这条进化线请刻进脑子:

```
one-hot → 词袋 BoW → TF-IDF → 静态词向量 word2vec/GloVe → 动态上下文向量 ELMo/BERT/GPT
稀疏无语义   丢顺序      加权重      稠密近义词靠近            一词千面随上下文变化
```

### 第一代:one-hot 与词袋——知道"有什么",不懂"是什么"

**one-hot**:每个词一个超长向量,自己是 1 其他全 0。
问题:维度=词表大小(5万+维);任意两词都正交,**"猫"和"狗"的距离等于"猫"和"导弹"的距离**——零语义。

**词袋(Bag of Words)**:整句 = 各词 one-hot 相加,只记词频。
"我爱北京"和"北京爱我"是同一个袋子——**语序全丢**,而中文里这是致命的("狗咬人"≠"人咬狗")。

**TF-IDF**:给词袋加权,判断哪些词对这篇文档重要:

$$\text{TF-IDF}(t,d) = \underbrace{\text{词频 } t \text{ 在 } d \text{ 中出现比例}}_{\text{这篇文章有多爱用这个词}} \times \underbrace{\log\frac{N}{1+\text{含 } t \text{ 的文档数}}}_{\text{这个词在全体文档中多稀有}}$$

💡 直觉:**"的"人人都在说 → 权重低;"卷积神经网络"只有技术文档爱提 → 权重高**。至今仍是搜索/召回工程的常用信号。

### 第二代:word2vec——词义的黄金时代(2013)

天才思想一句话:**看一个词周围总跟谁出现,就知道它是什么意思**(Firth:"You shall know a word by the company it keep" 共现即语义)。

两种训练模式:
| 模式 | 任务 | 💡类比 |
|---|---|---|
| **CBOW** | 用周围词猜中间词 | 完形填空:_ _ _ 到站了 → 公交车? |
| **Skip-gram** | 用中间词猜周围词 | 给中心词出题联想它的邻居(小语料上效果通常更好) |

训练完成后,每个词变成一个 50~300 维稠密向量(**词嵌入 embedding**),神奇性质自动涌现:

$$\vec{king} - \vec{man} + \vec{woman} \approx \vec{queen}$$

语义能做算术!说明向量空间中的**方向对应了语义关系**(性别方向、时态方向、国-首都方向……),近义词语味相近(余弦相似度高)。

⚠️ **静态表示的天花板**:"苹果发布新机"里的"苹果"和"苹果真甜"里的"苹果"共享同一个向量——一词多义没法区分;成语反讽更是重灾区。这就是后来 ELMo(按上下文动态编码)、BERT、GPT 用整个 Transformer 替换它的根本原因:**让每个词在不同句子里有不同的向量**——"动态/上下文相关表示",这是现代 LLM 表示观的核心(下一章主角)。

> 补充:${GloVe}$(全局共现矩阵分解,兼取两者)、${FastText}$(子词级,能兜住没见过的拼写变体)——面试被问词向量史时各带一句即可。

## 3.3 经典任务流水线:先分词,再理解

传统 NLP 是一条精细分工的流水线(2020 年前的主流形态):

```
原始文本 → 清洗 → 分词 → [词性标注/句法分析] → [NER 实体识别] → 高层任务(情感/分类/摘要/翻译)
           └──每一步都是独立模型,错误层层向后传递──┘
```

- **分词(中文特难)**:英文有空格天然切开;中文要靠统计模型(jieba)/序列标注(HMM/CRF/Viterbi 解码)。上面"南京市长江大桥"就是经典考题。⚠️ 注意:LLM 时代主流路线是 BPE 子词切分(第四章详解),"分词"作为独立任务已基本消失,但其直觉仍重要。
- **NER**:识别人名/地名/机构/时间("把会议推到下周三点找王总"→ 时间:下周三点;人名:王总)。今日由 LLM 直接抽取替代。
- **句法分析**:主谓宾依存树——LLM 内隐学到了,显式分析已罕见。

💡 历史视角:**端到端革命**把这些独立模块全部吞掉了。这就是第一章说的"表示的革命":人工特征 → 学习特征 → 连流水线结构本身也被学习取代。但遇到长文档处理、专业领域,很多老思想(滑动窗口、词典匹配、规则后处理)仍在工程角落发光。

## 3.4 序列建模三朝元老:HMM → CRF → RNN/LSTM

| 模型 | 一句话原理 | 强项 | 今天的位置 |
|---|---|---|---|
| HMM 隐马尔可夫 | 只看当前状态转移概率+发射概率(马尔可夫假设:不记得更早) | 语音识别早期/分词 | 思想仍在(维特比解码) |
| CRF 条件随机场 | 全局考虑整条标签序列的合理性(B-I-O 标签不能乱跳) | NER 标签连续性约束 | 有时作为 BERT 后的小配件 |
| RNN/LSTM/GRU | 维护隐状态逐 token 读入(第二章讲过) | 能记住一点上文 | 已被 Transformer 全面替代 |

⭐ 这三个都是"为序列而生"的努力:都想解决"**下一个词依赖前面所有词**"这个本质难题。共同困境:**远距离信息衰减 + 无法并行训练**。故事讲到 2014 年,迎来关键转折——

## 3.5 Seq2Seq 与 Attention 的诞生(本章最重要一节)

**机器翻译的 Seq2Seq 架构(2014 Sutslover 等)**:

```
输入句:ILoveYou(英文)                     输出句:我 爱 你(中文)
   │                                           ↑
 编码器 RNN ──→ 一个固定向量 C(context) ──→ 解码器 RNN 逐步生成
              ⚠️ 所有信息挤这一个瓶颈!
```

**痛点一目了然**:不论输入多长,全部压缩成一个固定向量 C。翻译 50 词的长句,前半句的信息早就稀释没了(信息瓶颈),而且译到第 30 个词时,回头"看原文具体某处"根本做不到。

**Attention(注意力)登顶 Bahdanau 2014**:

> 既然 decoder 每一步需求不同,凭什么只给一个固定 C?
> **让它在生成每个输出词时,自己回头'看'源句的所有位置,并按相关度加权取用。**

三个动作:对齐打分(s.decoder 当前态 × s.encoder 各位置)→ softmax 归一化成权重分布 → 加权求和得 context 向量。

💡 **直白类比:开卷考试开挂**。以前是把全书读完合上凭记忆答题(C 固定向量);现在是允许翻书——写到哪一道,精准回到课本对应页码划重点。性能立刻起飞,BLEU 大涨。

这时的 Attention 还只是 RNN 系统里的"外挂"。直到 2017 年有人开始想一个嚣张的问题:

> **既然注意力机制这么能干,那……把 RNN 本体扔掉行不行?**

于是:《Attention Is All You Need》——这就是通往第四章的门。

## 3.6 NLP 评估标尺

| 指标 | 用于 | 直觉计算 |
|---|---|---|
| Accuracy | 分类 | 对了几题/总题数(类别均衡时可用) |
| Precision / Recall / F1 | 抽取类(NER)/不平衡二分类 | 查准率(报出来的有多少是对的)/查全率(该报的报出了多少);F1 二者调和平均 |
| BLEU | 机器翻译 | n-gram 重合度(1~4 gram 几何平均×短句惩罚) |
| ROUGE | 摘要 | 与参考答案的 recall 型 n-gram 重合 |
| Perplexity 困惑度 | LM 训练 | 下一个词的"平均候选困惑度",越低拟合越好(实际词表选择越少犹豫) |

⚠️ 这些指标今天仍然在用,但都要带着一句批评读:**n-gram 类指标与人类判分相关性一般**(参考答案唯一性问题);LLM-as-a-Judge 正在新一代场景全面接管(GPT-4 当裁判打分)。BLEU 时代正在落幕,但 PERPLEXITY 这种基于概率的指标在大模型训练监控里永远活着。
