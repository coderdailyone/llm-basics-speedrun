## 第 7 题（编程题·改错题）

**题目描述**：
某同学做迁移学习：加载一个预训练模型，想在自己的数据上微调整个网络。但训练时发现损失下降一点点就停滞，最终效果远不如预期。代码如下：

```python
model = load_pretrained_model()          # 加载预训练模型
model.fc = nn.Linear(512, 5)             # 换成自己任务的 5 分类输出层

criterion = nn.CrossEntropyLoss()
# 构建优化器
optimizer = torch.optim.Adam(model.fc.parameters(), lr=1e-4)

model.train()
for epoch in range(20):
    for x, y in train_loader:
        optimizer.zero_grad()
        loss = criterion(model(x), y)
        loss.backward()
        optimizer.step()
```

（注：优化器只会更新**创建时传给它**的那些参数；没有传入的参数即使算出了梯度也不会被更新。）

(1) 该同学的目标是"微调整个网络"，上述代码实际在更新哪些参数？问题出在哪一行？
(2) 解释为什么"只有最后一层在学、其余层全部冻结"会导致损失快速停滞、效果受限。
(3) 请修改代码，使整个网络都参与微调。
(4) 引申：反过来，如果本来就只想训练最后一层（线性探测），除了只把 `model.fc.parameters()` 传给优化器，还可以对其余参数做什么设置来节省显存和计算？
