## 第 7 题（编程题·改错题）

**题目描述**：
某同学实现了一个能调用工具的简单智能体主循环。上线后发现：有时程序会卡死不返回，有时一个工具报错就整个崩溃。代码如下：

```python
def run_agent(task):
    messages = [{"role": "user", "content": task}]
    while True:
        reply = llm_chat(messages)          # 调用大模型
        if reply.tool_call is None:         # 模型给出最终答案
            return reply.content
        result = execute_tool(reply.tool_call)   # 执行模型请求的工具
        messages.append({"role": "tool", "content": result})
```

（注：`execute_tool` 在工具执行失败时会抛出异常；大模型有时会反复请求同一个工具，陷入循环而不给出最终答案。）

**请回答以下问题**：
(1) 上述代码存在哪两个问题？
建议从以下角度组织答案：循环的退出条件是否完备；工具失败时会发生什么；
(2) 解释为什么"模型反复请求工具"会导致程序永远不返回，以及为什么这在智能体中并不罕见。
(3) 请修改代码：加入最大步数限制；工具出错时不崩溃，而是把错误信息告诉模型让它调整策略。
(4) 引申：如果这个智能体拥有"发送邮件"权限，你认为在循环中还应加入什么机制？

**答题要求**：
请在下方答题区作答，建议作答时长 20 分钟。

## 第 8 题（编程题·构建智能体主循环）

**题目描述**：
现要求实现一个带安全限制的智能体主循环，逻辑如下：

1. 把用户任务放入消息列表；
2. 循环最多 `max_steps` 步：调用模型 → 若模型给出最终答案则返回；若模型请求工具则执行工具、把结果追加进消息列表，继续下一轮；
3. 超过最大步数仍未完成，返回超时提示。

为了帮助完成程序，现给出框架：

```python
def run_agent(task, max_steps=10):
    messages = [{"role": "user", "content": task}]

    # 循环最多 max_steps 步
    for step in range( [①] ):
        reply = llm_chat(messages)

        # 模型给出最终答案:没有工具调用请求
        if reply.tool_call is None:
            return [②]

        # 否则执行模型请求的工具
        result = execute_tool(reply.tool_call)

        # 把工具结果追加进消息列表,供下一轮参考
        messages.append({"role": "tool", "content": [③] })

    # 超过最大步数仍未完成
    return [④]
```

**请回答以下问题**：
请在下方空白处填入代码：
(1) [①] 循环次数
(2) [②] 应返回的内容（模型的最终回答）
(3) [③] 追加的消息内容（工具的执行结果）
(4) [④] 超时的返回值（一句合适的提示字符串）
