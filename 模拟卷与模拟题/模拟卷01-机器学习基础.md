## 第 7 题（编程题·改错题）

**题目描述**：
某同学用 PyTorch 训练一个分类网络，发现训练损失几乎不下降，模型学不到东西。训练代码如下：

```python
model = SimpleNet()
criterion = nn.CrossEntropyLoss()
optimizer = torch.optim.SGD(model.parameters(), lr=0.01)

model.train()
for epoch in range(10):
    for x, y in train_loader:
        outputs = model(x)
        loss = criterion(outputs, y)
        loss.backward()
        optimizer.step()
    print(f"epoch {epoch}, loss = {loss.item():.4f}")
```

（注：PyTorch 中，`loss.backward()` 计算出的梯度会**累加**到参数的 `.grad` 属性上，而不是覆盖它。）

**请回答以下问题**：
(1) 上述训练代码存在什么问题？
建议从以下角度组织答案：找出循环中缺失的关键步骤；
(2) 结合"梯度会累加"这一特性，解释为什么这个缺失会导致参数更新方向越来越混乱、损失不下降。
(3) 请修改代码，使模型能够正常训练。（此处给出补全后的循环体即可）
(4) 有一种技巧叫"梯度累积"，会故意隔几个批次才清空一次梯度。请说明这种技巧通常用来解决什么问题。
