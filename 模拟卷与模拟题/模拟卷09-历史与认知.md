## 第 7 题（编程题·改错题）

**题目描述**：
某同学想复现"多层网络能解决异或（XOR）问题"的经典实验，用 numpy 写了一个两层网络。但无论训练多久，模型都学不会 XOR。网络前向传播代码如下：

```python
import numpy as np

# XOR 数据:输入两位,输出它们的异或
X = np.array([[0,0],[0,1],[1,0],[1,1]])
y = np.array([0, 1, 1, 0])

# 两层网络的前向传播
def forward(X, W1, b1, W2, b2):
    h = X @ W1 + b1        # 第一层
    out = h @ W2 + b2      # 第二层
    return out
```

（注：历史上，单层感知机被证明无法解决 XOR 问题，这一批判曾让神经网络研究停滞近二十年；后来人们发现多层网络可以解决 XOR——但需要一个关键成分。）

**请回答以下问题**：
(1) 上述"两层"网络存在什么问题？它在数学上等价于什么？
建议从以下角度组织答案：两个线性变换连续作用的复合结果是什么；
(2) 解释为什么这样的网络无论怎么训练都解不了 XOR（提示：XOR 的四个点无法用一条直线分开）。
(3) 请修改代码，加入缺失的成分（如在第一层后加 ReLU：`np.maximum(0, ...)` 或 sigmoid），使网络具备解决 XOR 的能力。
(4) 这段"单层不行、多层加了它才行"的历史对应 AI 史上的哪一段公案？它给了我们什么教训？
