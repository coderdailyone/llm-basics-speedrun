## 第 7 题（编程题·改错题）

**题目描述**：
某同学训练一个文本分类模型，使用交叉熵损失。代码如下：

```python
model = TextClassifier()
criterion = nn.CrossEntropyLoss()
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)

model.train()
for x, y in train_loader:
    optimizer.zero_grad()
    logits = model(x)                    # 形状 [batch, num_classes]
    probs = F.softmax(logits, dim=-1)    # 先转成概率
    loss = criterion(probs, y)           # 再计算交叉熵
    loss.backward()
    optimizer.step()
```

训练能跑通，但收敛明显偏慢、最终效果差。

（注：PyTorch 的 `nn.CrossEntropyLoss` **内部已经包含了 softmax**（准确说是 log-softmax）计算，它期望的输入是未经归一化的原始得分 logits。）

**请回答以下问题**：
(1) 上述代码存在什么问题？
建议从以下角度组织答案：分析损失函数实际收到的输入经历了几次 softmax；
(2) 解释为什么"重复 softmax"会让概率分布被过度压平、梯度变小，从而拖慢收敛。
(3) 请修改代码，使损失计算正确。
(4) 引申：如果想在预测阶段得到各类别的概率（而非训练损失），应该对 logits 做什么操作？
