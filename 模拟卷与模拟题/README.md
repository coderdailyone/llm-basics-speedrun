# 模拟卷与模拟题

配套《大模型基础知识速通》教材的分层测评题库。

## 卷面结构（所有卷统一）

| 题号 | 类型 | 建议用时 | 说明 |
|---|---|---|---|
| 第 1~3 题 | 基础题 | 各 10 分钟 | 主观简答，200~300 字 |
| 第 4~6 题 | 前沿题 | 各 15 分钟 | 主观简答，200~300 字 |
| 第 7 题 | 编程题 · 改错 | 20 分钟 | 找出代码缺陷、解释机制、给出修复 |
| 第 8 题 | 编程题 · 构建 | 25 分钟 | 参照示例补全 ①②③④ 四处空白 |

整卷建议用时约 2 小时。

## 使用建议

- **学完一章测一章**：按上表"对应章节"选卷，答不出就回教材重读该章。
- **模考**：任选一卷计时 2 小时完整作答，再对照教材自评（主观题看要点覆盖，编程题跑一遍代码验证）。
- **对照答案**：目前仅原卷附参考答案；十份模拟卷的题目均可在三版教材中找到答案出处，建议先自答再查证。
