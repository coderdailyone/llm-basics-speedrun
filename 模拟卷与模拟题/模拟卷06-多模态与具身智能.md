## 第 7 题（编程题·改错题）

**题目描述**：
某同学用一组图像向量和文本向量做"以文搜图"：计算文本向量与每张图片向量的点积作为相似度，取最大者返回。但检索结果很差，返回的总是那几张固定的图片。代码如下：

```python
import numpy as np

def search(text_vec, image_vecs):
    # text_vec: [64],  image_vecs: [N, 64]
    sims = image_vecs @ text_vec        # 用点积作为相似度
    best = np.argmax(sims)
    return best
```

排查发现：那几张总被返回的图片，其向量的数值普遍偏大（向量长度/范数远大于其他图片）。

（注：点积 = 两向量的余弦相似度 × 两向量长度的乘积。若向量长度差异很大，点积大小可能主要由长度决定，而不是方向（语义）决定。）

**请回答以下问题**：
(1) 上述代码存在什么问题？
建议从以下角度组织答案：分析点积同时受哪两个因素影响；
(2) 解释为什么范数大的图片向量会"霸榜"，即使它们的语义与查询无关。
(3) 请修改代码：在计算相似度前对向量做 L2 归一化（提示：向量除以自身的范数 `np.linalg.norm`，注意 `image_vecs` 要按行归一化）。
(4) 引申：归一化之后的点积等价于什么相似度度量？为什么它更适合衡量语义相近程度？
