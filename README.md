## 阅读建议

完整路线是 `01 → 02 → 03 → 04 → 05 → 06 → 07 → 08 → 09 → 10`。只想先理解 LLM，可读 `01 → 03 → 04 → 08 → 10`；准备做应用，可边读边实现一个带检索、引用和只读工具的资料助手。

GPT 版每章都按同一学习契约组织：先看“本章地图”，再读机制和公式，完成 🧪 实验，最后回答 ❓章末自测。正文中的标记含义如下：

- 💡 类比：建立直觉，同时说明类比的边界
- ⭐ 核心考点：值得复述或画图的定义、公式和决策
- ⚠️ 易错误解：容易导致错误判断的说法
- 🧪 动手实验：低门槛、可记录、可复核的练习

## GPT 版的四个贯穿问题

1. **表示的革命**：输入被怎样编码，哪些信息被保留？
2. **规模的力量**：数据、参数、上下文或测试时计算改变了什么？
3. **先验与数据的拔河**：哪些假设写进结构，哪些交给数据学习？
4. **能力的代价**：新能力带来什么失败模式、成本和责任？
