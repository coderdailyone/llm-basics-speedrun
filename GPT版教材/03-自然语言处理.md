# 第三章 自然语言处理

## 本章地图

语言的难点不在于“字符很多”，而在于同一串字符会随着上下文改变意义。本章沿着表示的演化来讲：one-hot 只标身份，词袋只数共现，TF-IDF 找稀有线索，word2vec 把相似词放近，Seq2Seq 处理输入输出，Attention 让模型按需取回信息。每一步都在修补前一步丢失的结构。

## 3.1 先理解语言的不确定性

“苹果发布了新手机”中的苹果是公司，“苹果很甜”中的苹果是水果；“银行边上”既可能是金融机构，也可能是河岸。人类依靠语境、常识和语气消歧，机器只能从数据中学习这些线索。

语言还有组合性：词的数量有限，句子却可以无限组合；还有省略、反讽、指代和跨句关系。一个模型即使认识每个词，也不一定能理解“他把杯子放桌上，然后它碎了”里的“它”指什么。

💡 **类比**：单词像乐谱里的音符，意义来自前后和声。把音符按字母排序可以统计出现次数，却无法还原一首歌。

## 3.2 第一代表示：把词变成可数的对象

### One-hot 与词袋

假设词表有 `V` 个词，每个词用 `V` 维向量表示，自己的位置为 1，其余为 0。不同词向量之间距离相同，`猫` 和 `狗` 与 `猫` 和 `火箭` 没有区别。词袋模型进一步忽略顺序，只统计一篇文档包含哪些词。

### TF-IDF：给稀有词加权

词频 `TF(t,d)` 统计词 `t` 在文档 `d` 中出现的次数；逆文档频率 `IDF(t)=log(N/df(t))`，其中 `N` 是文档总数，`df` 是包含该词的文档数。组合后：

$$\text{TF-IDF}(t,d)=\text{TF}(t,d)\times\log\frac{N}{df(t)}$$

“的”在每篇文档都出现，IDF 很低；罕见的产品型号在少数文档出现，权重较高。TF-IDF 仍然不懂语义，却是便宜、可解释的检索基线。

⚠️ 中文需要先决定分词方式；不同分词器会改变 TF-IDF 的结果。今天的子词 tokenizer 不等于传统中文分词，不能混为一谈。

## 3.3 第二代表示：分布式词向量

分布式假设是：**一个词的意义由它经常和谁一起出现决定**。word2vec 不直接标注词义，而是训练一个小网络完成预测任务。

- CBOW：给定上下文预测中心词，训练快、对高频词稳定。
- Skip-gram：给定中心词预测上下文，对稀有词更友好。

训练完成后，隐藏层的权重就是词向量。向量空间会出现近邻和方向关系，例如某些语料中 `国王-男人+女人` 接近 `王后`。这不是词典规则，而是统计共现压缩出的几何结构。

⭐ 词向量的关键贡献不是“把词变成数字”，而是让相似性可以用距离表达，从而把分类、聚类和检索变成可计算的问题。

### 静态向量的天花板

一个词只有一个向量，无法区分“苹果公司”和“苹果水果”，也无法表达句法角色。ELMo 用双向语言模型让表示依赖上下文；BERT 和 GPT 进一步用 Transformer 在每层更新 token 表示。表示从“词的身份证”变成“词在这句话里的状态”。

## 3.4 序列模型：让顺序进入计算

### HMM 与 CRF

隐马尔可夫模型把词性或实体标签视为隐藏状态，假设当前状态只依赖前一个状态；维特比算法寻找最可能的整条路径。条件随机场直接建模给定句子的标签序列，可以加入更丰富的特征并保证全局转移一致。

### RNN 与 LSTM

RNN 把上一步隐藏状态传给下一步，能够表达顺序，但长句需要把信息挤进一个不断更新的向量。LSTM 用输入、遗忘、输出三个门控制记忆，减轻梯度消失，却仍然串行，训练难以充分利用 GPU。

## 3.5 Seq2Seq：把一个序列变成另一个序列

机器翻译、摘要和对话都可以写成 `输入序列 → 输出序列`。早期 Seq2Seq 用编码器读完整句，压成固定向量 `c`，解码器从 `c` 逐词生成：

```
源句 x1,x2,...,xn → 编码器 → c → 解码器 → y1,y2,...,ym
```

句子一长，所有细节都要塞进 `c`，信息瓶颈立刻出现。Attention 的解决方式是：解码每个 `y_t` 时，重新查看所有编码状态 `h_i`，并按相关性加权：

$$c_t=\sum_i\alpha_{t,i}h_i,\qquad
\alpha_{t,i}=\frac{\exp(e_{t,i})}{\sum_j\exp(e_{t,j})}$$

`e` 是当前解码状态与源位置的匹配分数。模型不必把整句压成一张照片，而是每一步打开最相关的几页笔记。

💡 **类比**：导游翻译长合同，不会先背下全文再翻译；他会在翻到某个条款时回看原文相关段落。Attention 就是可学习的回看动作。

## 3.6 从 Attention 到 Transformer

2017 年的 Transformer 证明：如果让序列中每个位置直接和其他位置交互，可以去掉 RNN 的串行依赖。自注意力使用 Query、Key、Value 三组向量计算相关性，后文第四章会逐项拆解。

它带来两个交换：

1. 训练阶段可并行处理整句，吞吐大幅提升；
2. 每个位置都能访问长距离信息，但注意力矩阵随长度 `n` 产生 `n×n` 的计算和显存开销。

位置编码用于补回顺序信息。正弦编码不需要额外参数，可学习位置向量更灵活，RoPE 则用旋转让相对距离自然进入 Q/K 的内积。

## 3.7 NLP 任务与评测

| 任务 | 输入与输出 | 常用指标 | 主要陷阱 |
|---|---|---|---|
| 分类 | 文本→标签 | Accuracy、F1 | 类别不平衡时 Accuracy 会骗人 |
| 命名实体识别 | 文本→实体跨度 | Precision、Recall、F1 | 边界定义不一致 |
| 翻译 | 源句→目标句 | BLEU、COMET | 一个意思有很多合法表达 |
| 摘要 | 长文→短文 | ROUGE、人工事实核验 | 复述多不代表忠实 |
| 语言模型 | 前文→下一 token | Perplexity | 低困惑度不等于有用或安全 |

评测必须和使用场景绑定。开放式生成不能只看 n-gram 重合；医疗摘要要测遗漏与捏造，客服要测是否正确升级，检索要测召回率和引用准确率。

⚠️ 测试集污染会让分数失真。评测集被用于提示调优、训练或模型选择后，它就不再是“未见过的考试”。

## 3.8 现代 NLP 的三层流水线

一个可维护的文本系统往往分三层：

1. **规范化层**：统一编码、去除无意义空格、识别语言和敏感字段；
2. **检索与表示层**：关键词召回保证精确命中，embedding 召回覆盖同义表达，再用重排器综合排序；
3. **生成或决策层**：LLM 生成答案、分类器输出标签，最后由规则和人工检查兜底。

这种分层比“让一个模型包办所有事情”更容易定位问题。召回不到资料是检索问题，资料正确但回答捏造是生成或提示问题，答案正确却泄露隐私则是流程问题。

长文档还需要切块。块太小会失去上下文，太大则浪费 token；重叠窗口、标题层级和表格解析会影响召回。评测时分别测召回率（证据是否找齐）和忠实度（回答是否只基于证据），不要用一个总分掩盖两种失败。

### 语言模型的概率视角

困惑度可以理解为模型面对下一个 token 时的平均“犹豫程度”：

$$\operatorname{PPL}=\exp\left(-\frac{1}{T}\sum_t\log P(x_t|x_{<t})\right)$$

低困惑度表示更能预测语料，但不同 tokenizer、领域和长度不可直接横比。一个模型可以在新闻续写上很顺，却在医学事实问答上不可靠。评测应报告数据来源和分词方案，避免把数字神化。

这也是“语言模型会说话”与“语言模型说得对”的分界：前者是概率拟合，后者还需要证据和任务约束。

## 🧪 动手实验：比较三种表示

选十条关于电影的短句。先用词袋统计关键词，再计算 TF-IDF，最后用任意现成 embedding 做相似度排序。找一组词面不同但意思相近的句子，以及一组词面相同但语境相反的句子，记录三种方法各自排对和排错的原因。
