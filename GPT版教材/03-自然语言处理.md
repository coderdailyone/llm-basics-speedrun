# 第三章 自然语言处理：给句子装上一套坐标系

## 本章地图

计算机看到的文本是字符序列，读者看到的文本却包含语境、语气、常识和省略。本章把“读懂”拆成表示问题：先用符号和计数表示，再用共现训练词向量，最后让表示随上下文变化。序列模型和 Attention 会作为一条历史线出现，而不是一串需要背诵的模型名。

## 3.1 语言为什么难

“他把鱼放进冰箱，因为它太大了”里的“它”可能指鱼，也可能指别的对象；“银行旁边有一条河”里的“银行”有两种词义；“你真是太准时了”可能是表扬，也可能是讽刺。机器需要从上下文和世界知识推断，而不是只查词典。

语言还具有组合性。有限词汇能组成无限句子，词序会改变关系，否定会反转结论，省略会把信息藏在前句。一个系统若只记住词频，无法回答“没有下雨时，比赛是否仍取消”这类反事实问题。

💡 **类比**：字符像乐谱上的单个音符，意义更像旋律。把音符收集得再全，如果不记录前后关系，也无法还原歌曲。

## 3.2 表示一：符号与词袋

### One-hot

设词表大小为 `V`，每个词用 `V` 维向量表示，自己的位置为 1，其余为 0。它保留了身份，却没有“猫”和“狗”相近、“猫”和“火箭”较远的概念。词表变大时，向量也变得稀疏而昂贵。

### 词袋

词袋把文档表示成词的计数，忽略顺序。它适合垃圾邮件分类和快速检索，因为主题词常常已经足够；但“狗咬人”和“人咬狗”得到相同计数，否定和长距离关系也被丢掉。

### TF-IDF

词频 `TF(t,d)` 衡量词在文档 `d` 中出现多不多；逆文档频率 `IDF(t)=log(N/df(t))` 衡量它在整个语料中稀不稀有：

$$\operatorname{TFIDF}(t,d)=\operatorname{TF}(t,d)\cdot\log\frac{N}{df(t)}$$

“的”在几乎所有文档中出现，IDF 很低；一个罕见型号可能成为很好的检索线索。TF-IDF 可解释、便宜、易调试，所以即使有大模型，仍值得保留作基线。

⚠️ TF-IDF 的结果依赖分词、停用词、大小写和文档集合。换一套预处理，分数就可能改变；它不是“词义相似度”的万能公式。

## 3.3 表示二：从共现学习词义

分布式假设认为，出现在相似邻居中的词往往有相似意义。word2vec 用预测任务学习一个稠密向量：

- CBOW 用周围词预测中心词，训练快，对高频词稳定；
- Skip-gram 用中心词预测周围词，对稀有词更有帮助。

训练完成后，隐藏层的权重就是词向量。余弦相似度衡量两个向量方向：

$$\cos(u,v)=\frac{u\cdot v}{\|u\|\|v\|}$$

某些语料中会出现“国王-男人+女人≈王后”的方向关系。它不是词典写入的规则，而是共现统计形成的几何现象。

### 静态向量的问题

一个词只有一张“身份证”，无法同时表示“苹果公司”和“苹果水果”。它也很难表达句法角色、否定和指代。ELMo 让表示依赖双向上下文，BERT 与 GPT 使用 Transformer 在每个位置持续更新状态，词向量由静态坐标变成句中状态。

## 3.4 表示三：让顺序参与推断

### HMM

隐马尔可夫模型把词性等标签视为隐藏状态，假设当前状态主要依赖上一个状态。观测概率描述“这个词像不像某种标签”，转移概率描述标签序列是否常见，维特比算法寻找最可能的完整路径。

### CRF

条件随机场直接为整条标签序列打分，可以加入词形、邻近词和标签转移特征。它比逐词独立分类更能保证“B-PER 后面接 I-PER”之类的全局一致性。

### RNN 与 LSTM

RNN 逐步更新状态：

$$h_t=\phi(W_xx_t+W_hh_{t-1}+b)$$

早期信息需要经过很多次矩阵乘法才能影响后面，梯度容易消失或爆炸，训练也难以并行。LSTM 用门控制读写记忆，缓解了长期依赖，但没有消除串行瓶颈。

## 3.5 Seq2Seq：翻译时不要把整本书压成一句话

编码器—解码器把源序列压成上下文 `c`，再逐词生成目标序列：

```
x1 x2 ... xn → 编码器 → c → 解码器 → y1 y2 ... ym
```

句子变长后，固定 `c` 成为信息瓶颈。Attention 让每一个解码时刻重新查看编码器的所有状态：

$$c_t=\sum_i\alpha_{t,i}h_i,\qquad
\alpha_{t,i}=\frac{\exp(e_{t,i})}{\sum_j\exp(e_{t,j})}$$

`e_{t,i}` 是当前解码状态和源位置的匹配分数。翻译到某个词时，模型可以把注意力集中到对应的原文片段，而不是依赖一张模糊的总摘要。

💡 **类比**：翻译长合同的律师会不断翻回原文查定义和例外条款；Attention 把这种“按需回看”变成可学习的权重。

## 3.6 Attention 迈向 Transformer

Attention 不必绑定 RNN。Transformer 让序列位置直接互相读取，训练阶段可并行处理整句，长距离路径也缩短了。代价是要计算大量位置对之间的关系，序列长度增加时内存和计算增长很快。

注意力本身不懂先后顺序，需要位置编码。绝对位置向量把“第几个位置”加进去，RoPE 用旋转让相对距离影响 Query 与 Key 的内积。第四章会把这套机制放进大语言模型。

## 3.7 NLP 任务不是同一张考卷

| 任务 | 输出 | 常见指标 | 指标盲点 |
|---|---|---|---|
| 分类 | 一个或多个标签 | Accuracy、F1 | 类别不均衡会掩盖少数类错误 |
| 实体识别 | 文本跨度与类型 | Precision、Recall、F1 | 边界和标注规范不一致 |
| 检索 | 排序后的文档 | Recall@k、MRR、nDCG | 找到文档不代表读对 |
| 翻译/摘要 | 新文本 | BLEU、ROUGE、人工事实核验 | 同义表达被低估，捏造可能漏检 |
| 语言建模 | 下一个 token 概率 | Perplexity | 低困惑度不代表任务有用 |

测试集必须未参与训练和调参；长文档要分别测“证据是否召回”和“回答是否忠实”。一个总分不能替代错误分类表。

⭐ **核心考点：表示的三种损失**

词袋丢掉顺序，静态词向量丢掉语境，固定长度的 Seq2Seq 向量丢掉长句细节。每一次技术升级都不是凭空增加“智能”，而是减少一种信息损失：加入位置、加入邻居、加入动态回看。用“它挽救了哪种信息”来记模型，比按年份背名词更牢。

## 3.9 分词、子词和文本边界

传统 NLP 常把中文句子先切成词，再做分类或序列标注；大语言模型常用子词 tokenizer，训练与推理直接在 token 序列上进行。两者的边界不同：传统分词追求语言学可读性，子词切分追求词表覆盖和计算效率。数字、网址、代码、表情和混合语言是最容易出现异常的地方。

建立文本系统时要明确规范化规则：是否区分全角半角、大小写、繁简体、换行和隐私字段。过度清洗可能删掉否定或单位，清洗不足则让同一实体产生多个写法。把原文和处理后文本都保留，才能追查召回失败。

⭐ 处理语言最重要的能力不是“找到最复杂的模型”，而是知道信息在哪一步丢失：字符被错误切分、词义缺少语境、证据没有召回，还是生成阶段把推断写成了事实。

## 3.8 现代文本系统的分层

可维护的 NLP 应用往往拆成：编码与清洗、检索与重排、生成或决策、后处理与审计。关键词检索擅长型号和编号，向量检索擅长同义表达，重排器综合词面和语义，LLM 负责组织答案。分层的价值是让故障可定位：找不到证据、证据错误、模型捏造和权限泄露是四种不同问题。

## 🧪 动手实验：三种表示的对照

写十条关于电影的短句。用词袋计算重合词，再算 TF-IDF 排名，最后调用一个 embedding 模型做相似度排序。准备一组“词面不同但意思相近”和一组“词面相同但立场相反”的句子，分别记录三种表示为什么成功或失败。不要只看排名，要写出被丢掉的证据。
