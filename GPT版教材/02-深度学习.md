# 第二章 深度学习

## 本章地图

把神经网络想成一座会自我调音的乐队：神经元是乐手，权重是音量旋钮，损失函数是评分，反向传播告诉每个旋钮该往哪边转，优化器决定一次转多少。我们先用一个最小模型走通训练，再解释激活函数、正则化、CNN 与 RNN。数学只保留能帮助你预测行为的部分。

## 2.1 神经元：从加权和到“开关”

一个人工神经元接收输入 `x1, x2, ...`，给每个输入乘权重，加上偏置：

$$z = w_1x_1 + w_2x_2 + \cdots + w_nx_n + b$$

如果直接把 `z` 当输出，它只能表达线性关系。加入激活函数 `a=f(z)` 后，多个神经元叠起来才可以画出弯曲的决策边界。最常用的 ReLU 是 `f(z)=max(0,z)`：负数归零，正数原样通过。

💡 **类比**：餐厅的总评分是食材、服务、价格的加权和；偏置像店长的基础分；激活函数像“低于及格线就不推荐”的门槛。一个评分器很简单，许多评分器分层合作就能表达复杂偏好。

### 感知机为何卡在 XOR

单层感知机只能用一条直线把两类点分开。XOR 的四个点需要两条折线围出区域，因此必须使用隐藏层。这个例子不是为了记结论，而是提醒你：网络深度决定了可表达函数的形状，优化只是把参数找到。

## 2.2 前向计算：一层一层变换表示

一层网络可以写成 `h=f(Wx+b)`。多层网络反复执行：

```
原始输入 → 低级模式 → 局部组合 → 任务相关表示 → 输出
```

在图像中，早层可能响应边缘，后层组合出纹理和物体；在文本中，早层捕捉局部 token 关系，后层编码句法和语义。所谓“自动特征工程”，就是这些中间表示由损失函数间接塑造，而不是工程师逐列设计。

⭐ 参数量不等于神经元数量。矩阵 `W` 的每个元素都是参数；增加宽度、深度或词表都会增加不同类型的参数，实际记忆和计算还要看连接方式。

## 2.3 损失函数：把错误变成可优化的数字

分类任务常用交叉熵。若正确类别的预测概率为 `p`，单个样本损失是：

$$L=-\log p$$

模型把正确答案从 0.5 提升到 0.9，损失下降；如果自信地给错答案，损失会很大。回归常用均方误差：

$$L=\frac{1}{n}\sum_i(\hat y_i-y_i)^2$$

损失函数是工程选择，不是自然法则。把“点击率”当目标，模型就会优化点击；把“帮助性”当目标，模型会寻找评分器认可的语言。目标写错，训练再成功也会得到错误产品。

⚠️ 训练损失很低不代表泛化好。模型可能记住训练样本、利用数据泄漏或学到与任务无关的捷径。

## 2.4 梯度下降：在山谷里找低点

把所有参数写成向量 `θ`，梯度 `∇L(θ)` 指向损失上升最快的方向。最基本的更新是：

$$\theta_{t+1}=\theta_t-\eta\nabla_\theta L(\theta_t)$$

`η` 是学习率。太大像跨过山谷，损失震荡；太小像蚂蚁下坡，训练很慢。训练数据通常分成 mini-batch：每次只用一小批样本估计梯度，噪声反而有助于跳出尖锐的坏解。

### 优化器的三个旋钮

| 机制 | 直觉 | 常见实现 |
|---|---|---|
| 动量 | 记住前几步方向，减少来回摆动 | Momentum、SGD |
| 自适应步长 | 为不同参数调不同学习率 | Adam、AdamW |
| 权重衰减 | 偏好较小的参数，抑制过度记忆 | AdamW 的 decoupled decay |

学习率预热、余弦退火和梯度裁剪是训练大模型时的常规安全带。它们不是“魔法调参”，而是在控制更新的尺度与稳定性。

## 2.5 反向传播：链式法则的流水线

前向计算把输入变成损失；反向传播从损失往回走，利用链式法则计算每个参数对损失的偏导：

$$\frac{\partial L}{\partial w}=\frac{\partial L}{\partial y}\frac{\partial y}{\partial z}\frac{\partial z}{\partial w}$$

工程框架会保存中间激活，自动生成计算图并累积梯度。反向传播不是另一种学习算法，它只是高效求梯度的方法；真正改变参数的是优化器。

### 梯度消失与爆炸

深层网络把许多导数相乘。若多数小于 1，梯度会快速变小；若大于 1，就可能爆炸。ReLU、残差连接、归一化、合适初始化和梯度裁剪都是应对方式。Transformer 的残差路径让信息和梯度拥有一条“高速公路”。

## 2.6 泛化：模型是在理解还是在背题

把数据分为训练集、验证集和测试集：训练用来更新参数，验证用来选超参数，测试只在最后评估。若反复根据测试分数修改方法，测试集就被“偷看”，最终数字不再可信。

**过拟合**表现为训练误差继续下降而验证误差上升。正则化的共同思想是限制有效自由度：

- L2 权重衰减惩罚大权重；
- Dropout 随机关闭部分通道，迫使网络不要依赖单一路径；
- 数据增强改变样本表面，保留标签不变；
- 早停在验证集最优处停止；
- 减小模型或增加高质量数据。

💡 **类比**：只背答案的学生在原题得满分，换个问法就失分；练习不同表述、限制死记硬背并留一套未见过的题，才能测出真正的迁移。

## 2.7 CNN：把空间先验写进网络

卷积核是一个小矩阵，在图像上滑动，对局部窗口做乘加。一个 `3×3` 核只连接附近像素，且同一组权重在不同位置复用。这带来两个先验：**局部性**和**平移等变性**。池化或 stride 下采样可以扩大感受野、减少计算，但会牺牲精细位置。

经典 CNN 的进步包括：更深的层数、更稳定的激活和批归一化，以及 ResNet 的残差：

$$y=F(x)+x$$

即使新分支暂时学不到东西，恒等捷径也能传递信息和梯度。ResNet 解决的是“深了反而难训”，不是简单地增加准确率。

## 2.8 RNN：把序列压进一个状态

循环网络按顺序更新隐藏状态：

$$h_t=\phi(W_xx_t+W_hh_{t-1}+b)$$

它天然适合流式输入，早期用于翻译、语音和时间序列。问题是长序列需要反复乘 `W_h`，容易梯度消失；训练也难以并行。LSTM 用门控制记忆读写，改善了但没有消除串行瓶颈。

## 2.9 为什么下一站是 Attention

CNN 只能逐步扩大视野，RNN 必须沿时间传递状态。Attention 允许当前位置直接读取序列中相关位置，计算可以并行。它减少了长程依赖的路径长度，却把计算和显存开销推向序列长度的平方。第四章会解释这个交换为何值得。

## 2.10 训练日志应该看什么

一个最低限度的训练日志包含：训练/验证损失、主要指标、学习率、梯度范数、吞吐、显存和随机种子。若训练损失下降而验证指标不动，可能是过拟合或标签问题；若梯度突然变大，先检查学习率、数据异常和混合精度溢出；若指标跳动，可能是 batch 太小或评测集太少。

混合精度用较低位宽计算、较高位宽保存关键累计量，以减少显存并提高吞吐。梯度累积把多个小 batch 的梯度相加，再执行一次更新，相当于更大的有效 batch，但不会完全复制大 batch 的统计特性。分布式训练还要处理数据并行、参数同步、通信带宽和故障恢复。

⚠️ 只截图一条“准确率上升”的曲线无法证明改动有效。应固定数据切分，报告多次随机种子，保留基线和失败实验，并说明指标是否与真实目标一致。

## 🧪 动手实验：纸笔完成一次更新

取一个神经元，设 `x=[1,2]`、`w=[0.2,-0.1]`、`b=0`，用线性输出预测 `y=1`。算出预测值、平方误差，再手算 `∂L/∂w`，用学习率 `0.1` 更新一次。改变学习率重算，观察步子过大时为什么可能越过最优点。
