# 第五章 计算机视觉

## 本章地图

计算机看到的不是“物体”，而是像素矩阵。本章先把光线变成数字，再用卷积提取局部结构，理解 ResNet 怎样让网络变深；随后看 Vision Transformer 如何把图像切成 patch，CLIP 如何对齐图文，最后拆开 Diffusion 的加噪与去噪。主线仍是：表示改变了什么，先验节省了什么数据，生成能力又带来什么风险。

## 5.1 图像在机器里是什么

灰度图是 `H×W` 的数值表，彩色图通常是 `H×W×3` 的 RGB 张量。像素值可归一化到 `[0,1]` 或 `[-1,1]`。相邻像素往往相关，边缘是亮度变化大的区域，纹理是重复的局部模式。

图像任务的输出形态不同：分类输出一个类别，检测输出多个框和类别，语义分割给每个像素贴标签，实例分割还要区分同类物体。不要用分类准确率评价所有任务。

💡 **类比**：看一幅地图时，你可以问“这是哪个城市”（分类），圈出所有车站（检测），给每条道路涂颜色（分割）。问题不同，模型的输出接口就不同。

## 5.2 卷积：把局部规律变成特征

卷积核是小矩阵，在图像上滑动，逐元素相乘后求和。设输入 `X`、核 `K`，位置 `(i,j)` 的输出为：

$$Y_{i,j}=\sum_{u=0}^{k-1}\sum_{v=0}^{k-1}K_{u,v}X_{i+u,j+v}$$

同一个核在所有位置复用，参数量不随图像尺寸线性增加。边缘核会对水平或垂直变化产生高响应；多个卷积层可以把边缘组合为角点、纹理和物体部件。

卷积写入了两个先验：**局部连接**与**平移等变**。这让它比全连接网络更省参数、更适合图像，但也意味着远距离关系需要堆更多层或额外模块。stride 和池化扩大感受野、降低分辨率，却可能丢失小目标信息。

## 5.3 从 AlexNet 到 ResNet

AlexNet 在大规模图像数据和 GPU 上证明深度 CNN 的优势；VGG 用整齐的 `3×3` 卷积堆深网络；Inception 并行使用多种尺度的卷积。网络越深，表达能力通常越强，但训练会出现梯度难传和退化：更深模型的训练误差反而升高。

ResNet 引入残差块：

$$y=F(x)+x$$

捷径允许网络先近似恒等映射，优化器只需学习“需要改变的部分”。这不是把错误直接跳过，而是给信息和梯度提供稳定通路。BatchNorm、合理初始化和数据增强共同组成 CNN 的训练配方。

⭐ 看网络结构时，先问三件事：感受野如何增长？分辨率在哪些层下降？特征图的通道数怎样变化？这比死记网络名字更通用。

## 5.4 ViT：把图像变成 token

Vision Transformer 将图像切成固定大小的 patch，例如 `16×16`，把每个 patch 展平后线性投影成向量，再加位置编码，送进 Transformer。于是图像也变成一个序列：

```
图像 → patch 切分 → patch embedding + 位置 → 自注意力 → 分类/检测头
```

ViT 的局部先验较弱，数据量不足时可能不如 CNN；在海量预训练数据下，它能直接建模远距离关系，扩展性很好。层次化设计（如窗口注意力）用局部计算控制成本。

## 5.5 CLIP：在同一空间里对齐图片和文字

CLIP 用图像编码器得到 `v_img`，文本编码器得到 `v_txt`，对一批配对样本最大化正确图文的余弦相似度，压低错误配对相似度：

$$s(i,t)=\frac{v_i\cdot v_t}{\|v_i\|\|v_t\|}$$

训练后，可以把图片与“a photo of a cat”等文本提示比较，实现 zero-shot 分类和图文检索。它把语言作为视觉的标签接口，也为文本条件图像生成提供了语义空间。

⚠️ CLIP 的相似不等于事实理解。图片中的细小数字、空间关系、否定和偏见都可能被忽略；提示词换一种写法，分类结果也可能变化。

## 5.6 Diffusion：从噪声反推图像

扩散模型先在训练图像上逐步加高斯噪声，直到接近纯噪声，再训练网络预测噪声或干净图像。生成时从随机噪声开始，重复若干步反向去噪：

$$x_t=\sqrt{\bar\alpha_t}x_0+\sqrt{1-\bar\alpha_t}\epsilon,\quad \epsilon\sim\mathcal N(0,I)$$

模型学习在给定 `x_t`、时间步 `t` 和条件 `c` 时估计 `ε`。文本条件通常由文本编码器提供，U-Net 或 DiT 在每一步读取条件。Classifier-Free Guidance 用有条件与无条件预测的差异加强文本约束：

$$\hat\epsilon=\epsilon_{\text{uncond}}+s(\epsilon_{\text{cond}}-\epsilon_{\text{uncond}})$$

步数越多通常越慢但更易收敛，guidance 越高可能更贴提示却产生过饱和、畸变或构图僵硬。图像生成的“可控”来自条件接口和额外控制信号，不是模型拥有摄影机。

## 5.7 视觉系统的评估与风险

分类可看 Accuracy、宏平均 F1；检测常用 IoU 与 mAP；分割看像素准确率、Dice 或 IoU；生成图像则需要人评、CLIP 相似度、审美和安全测试的组合。医疗、工业和自动驾驶必须关注假阴性、分布外输入和传感器失效。

数据集的地域、肤色、年龄和拍摄条件会决定模型覆盖范围。扩散模型还可能复现训练图像的风格和人物特征，涉及版权、肖像和深度伪造问题。水印、来源追踪与人工审核要和模型能力一起设计。

## 5.8 视觉项目的工程取舍

分辨率、帧率和批大小共同决定显存与延迟。实时摄像头系统通常先用轻量检测器筛选，再把关键帧交给更强模型；离线质检则可以使用多尺度、高分辨率和多次投票。模型蒸馏让小模型模仿大模型，剪枝减少冗余通道，缓存相邻帧特征则减少重复计算。

数据增强要尊重任务语义：水平翻转适合许多自然图像，却会改变文字、交通标志或左右手器官；颜色抖动能提升光照鲁棒性，却可能破坏医学染色信息。增强不是越多越好，应该用验证集检查它是否保留了标签。

三维视觉把深度、点云和多视角几何加入表示。NeRF 用神经场从多张照片重建视角，3D Gaussian Splatting 用可渲染的高斯表示加速显示；它们适合建模和导航，却不自动解决物体可抓取性与物理碰撞。

⚠️ 生成图像的细节越逼真，来源和授权越重要。部署文生图功能时应记录提示、模型、LoRA、随机种子和编辑链，方便处理侵权与误导投诉。

## 5.9 从模型分数到真实视觉质量

视觉模型的错误经常具有长尾：罕见姿态、夜间场景、反光表面和遮挡目标在平均指标中占比很小，却可能决定系统是否可用。数据集应按环境和人群分层报告，线上还要监测输入分布是否漂移。遇到低置信度或分布外图像，系统可以退回人工或请求更清晰的照片，而不是强行给出一个类别。

对于生成模型，“更像提示词”与“更好看”并不总一致。评测应同时看语义符合度、构图、文字可读性、人物一致性和安全违规率；最好让真实用户完成任务，而不是只用一个自动分数。

在团队协作中，建立一组固定的“困难切片”比不断扩大随机测试集更有效：小字、遮挡、低光、少数人群和非主流视角都应单独追踪，发布新模型时逐项回归。

对检测与分割还要检查标注协议：框的边界、重叠物体和“未知”类别若没有统一规则，模型分数反映的可能只是标注差异，而不是视觉能力。

上线报告应同时给出平均值、困难切片和人工复核样本，避免一个漂亮的总分掩盖长尾风险。

## 🧪 动手实验：手算卷积与扩散直觉

写一个 `5×5` 灰度矩阵，使用 `3×3` 的水平边缘核，手算 stride=1 的输出，再做一次 `2×2` 最大池化。随后在表格中把一张小图片的像素逐步加入随机噪声，观察原结构何时消失；再尝试用“从模糊到清晰”的描述解释去噪过程。
