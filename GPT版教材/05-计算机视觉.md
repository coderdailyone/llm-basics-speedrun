# 第五章 计算机视觉：从像素到场景

## 本章地图

机器并不是“直接看见猫”，它接收的是一个数字张量。本章先说明像素、通道和空间关系，接着用一次卷积理解 CNN 的局部先验，再解释 ResNet 为什么让网络可以变深。随后把图像切成 patch 送进 ViT，用 CLIP 把图像和文字放进共同空间，最后从噪声出发拆开 Diffusion。读完要能区分识别、定位、分割和生成。

## 5.1 相机输出的是数字

一张灰度图可以表示为 `H×W` 矩阵，彩色图通常为 `H×W×3`，三个通道记录红、绿、蓝的强度。像素值经过归一化后成为神经网络输入。图像的特殊之处是邻近像素往往相关，边缘表现为局部变化，纹理表现为重复模式。

不同任务需要不同输出：分类回答“这是什么”，检测回答“它在哪里”，语义分割给每个像素贴类别，实例分割还要区分两个同类对象。把检测器的框当成分割结果，或者用分类准确率评价小目标漏检，都会得到错误结论。

💡 **类比**：看城市地图，问“这是哪座城市”是分类；圈出所有医院是检测；给每条道路涂颜色是分割。地图的表示方式随问题变化。

## 5.2 卷积核在寻找局部模式

一个 `k×k` 卷积核在局部窗口上滑动并做乘加：

$$Y_{i,j} = \sum_{u=0}^{k-1}\sum_{v=0}^{k-1}K_{u,v}X_{i+u,j+v}$$

同一个核在不同位置重复使用，因此参数量与图像尺寸无关；多个核形成多个输出通道，分别响应不同方向的边缘和纹理。stride 决定移动步长，padding 决定边缘是否补零，池化或步幅卷积降低分辨率。

卷积把两个先验写进结构：局部连接和平移等变。它不必从数据中重新发现“附近像素通常相关”，所以样本效率高；但远距离关系要经过多层传递，细粒度位置在下采样后可能丢失。

⭐ **手算要点**：卷积不是把整张图压成一个数字，而是在每个位置产生响应图。看懂响应图，比记住某个网络有多少层更重要。

## 5.3 深度、残差与表示层级

浅层网络只能组合少量局部模式，增加深度后可以形成“边缘→纹理→部件→物体”的层级表示。深度增加也带来优化退化：理论上更强的网络，训练误差却可能更高。

ResNet 用残差块：

$$y=F(x)+x$$

捷径让网络容易先学恒等映射，再学习需要的变化，梯度也有稳定通道。BatchNorm、合理初始化、数据增强和学习率计划共同决定训练是否稳定。残差连接解决的是优化路径问题，不是自动消除数据偏见。

## 5.4 从分类走向定位

检测模型通常输出类别、置信度和边界框，评价常用交并比：

$$IoU=\frac{|B_{pred}\cap B_{true}|}{|B_{pred}\cup B_{true}|}$$

在不同 IoU 阈值下综合精确率与召回率得到 mAP。分割模型则比较像素掩码，Dice 对小目标更敏感。医疗和自动驾驶场景需要特别关注假阴性：平均分数不应掩盖关键类别漏检。

## 5.5 ViT：把一张图改写成序列

Vision Transformer 把图像切成固定大小的 patch。每个 patch 展平后投影成向量，加上位置编码，像文字 token 一样输入 Transformer：

```
H×W×C 图像 → N 个 patch → patch embedding + position
             → 自注意力 → 分类或检测头
```

ViT 的局部先验比 CNN 弱，数据不足时容易过拟合；大规模预训练时，它能直接建模远距离区域关系，扩展更自然。窗口注意力、层次化 patch 和稀疏机制用于控制计算量。

## 5.6 CLIP：让图文相互定位

CLIP 为图片和文字各训练一个编码器。对配对图片 `i` 和文本 `t`，最大化相似度，压低同批次错误配对：

$$s(i,t)=\frac{v_i\cdot v_t}{\|v_i\|\|v_t\|}$$

得到共同 embedding 空间后，可以用“a photo of a bicycle”等提示做 zero-shot 分类，也能做图文检索。文本提供了开放类别的标签接口，图像不必为每个新类别重新训练分类头。

⚠️ 相似度不是事实证明。细小文字、数量、空间关系、否定和社会偏见都可能被忽略；更换提示模板也会改变分数。

## 5.7 Diffusion：把生成写成去噪问题

训练时逐步向真实图像 `x_0` 加噪：

$$x_t=\sqrt{\bar\alpha_t}x_0+\sqrt{1-\bar\alpha_t}\epsilon,\quad\epsilon\sim\mathcal N(0,I)$$

模型学习在知道 `x_t`、时间步 `t` 和条件 `c` 时预测噪声。生成时从随机噪声开始，反复执行反向去噪。文本条件由编码器提供，U-Net 或 DiT 预测每一步的方向。

Classifier-free guidance 混合有条件和无条件预测：

$$\hat\epsilon=\epsilon_u+s(\epsilon_c-\epsilon_u)$$

`s` 增大通常更贴合提示，但可能过饱和、构图僵硬或产生伪影。步数、采样器、分辨率和条件控制共同决定速度与质量。

## 5.8 视觉数据的先验与偏差

水平翻转对许多自然图像有效，却会改变文字、交通标志和左右器官；颜色增强能模拟光照，也可能破坏医学染色。增强规则必须服从标签语义。训练集中的人群、地域、相机和天气分布会影响模型覆盖，长尾场景需要单独切片评估。

生成模型还带来来源、肖像和版权风险。保存模型版本、提示、随机种子、控制条件和编辑链，才能处理争议；水印和来源认证应与内容审核一起设计。

## 5.9 视觉系统的工程分层

实时摄像头常用轻量模型筛选关键帧，再交给高精度模型；离线质检可使用多尺度和多次投票。蒸馏、剪枝、量化和特征缓存减少成本，但都要用困难切片回归。三维视觉加入深度和多视角几何，NeRF 与 3D Gaussian Splatting 能重建场景，却不自动保证可抓取性和物理碰撞安全。

## 5.10 视觉模型如何“看错”

错误可以按来源分层：

| 来源 | 例子 | 诊断方法 |
|---|---|---|
| 采集 | 逆光、模糊、镜头污渍 | 重拍、质量检测、传感器融合 |
| 表示 | 小字在缩放时消失 | 提高局部分辨率、改 patch 大小 |
| 数据 | 训练集缺少某类人或天气 | 分层统计、补充困难切片 |
| 目标 | 平均准确率掩盖少数高代价错误 | 代价加权、召回优先 |
| 部署 | 线上相机与训练相机不同 | 漂移监测、灰度和回滚 |

这种故障树适用于分类、检测和 VLM。先定位“模型没看见”还是“看见却解释错”，再选择数据、结构或流程上的修复。

### 生成与理解的边界

扩散模型可以生成符合统计风格的图像，但不保证每个物体遵守物理、文字和数量约束。VLM 能描述一张图，也可能把生成图中的伪影当成真实证据。需要事实的场景应把视觉输出当作候选观察，并让结构化检测器或人工复核承接关键判断。

## 5.11 视觉表示的选择题

面对一个新项目，可以按信息需求选表示：需要精确位置时保留高分辨率特征，需要全局关系时增加跨区域注意力，需要连续运动时加入时间轴，需要三维几何时使用深度或多视角。单张 RGB 图片无法凭空恢复被遮挡的深度和时间，模型再大也不能违反观测条件。

视觉问答还要区分三种输出：观察（画面中可直接证实的内容）、推断（根据观察得出的可能解释）、建议（下一步应该做什么）。把三者分栏能减少“模型的猜测被当成摄像头事实”的风险，也是 VLM 接入 Agent 时最实用的接口约定。

## 🧪 动手实验：从边缘到噪声

写一个 `5×5` 矩阵和 `3×3` 水平边缘核，手算卷积输出，再做 `2×2` 最大池化。然后在表格中逐步向一张小图加入随机噪声，记录轮廓何时消失。最后比较“分类、检测、分割”三个任务各需要什么输出，形成一张自己的任务卡。
