# 《大模型基础知识速通》课程总览

## 本章地图

这不是一个名词清单，而是一张从问题出发的地图。你会先问机器怎样获得智能，再追踪一串关键转变：规则变成数据，特征变成表示，小模型变成基础模型，单轮回答变成可调用工具的 Agent。最后把同一套能力放回现实世界，讨论它的成本、边界和责任。

全书 01~10 是十章主课，00 是导航和实验入口。每章都沿着四个问题行进：**输入被怎样表示？规模带来了什么？结构预先假设了什么？能力增加后谁承担代价？** 这四问是本书的贯穿母题。

## 三条学习路线

### 路线 A：完整通识（18~24 小时）

按 `01 → 02 → 03 → 04 → 05 → 06 → 07 → 08 → 09 → 10` 阅读。每章先看地图，正文只在卡住处停下来计算，最后完成自测。适合希望能读懂论文摘要、产品发布和新闻争论的人。

### 路线 B：先懂大模型（约 7 小时）

`01 → 03 → 04 → 08 → 10`。第三章提供“表示”的词汇，第四章是核心技术，第八章把模型接到工作流，第十章提醒你哪些结果不能直接交付。

### 路线 C：做一个小应用（约 10 小时）

`02 → 03 → 04 → 08 → 10`。边读边做一个“本地资料问答”原型：先用关键词检索，再接向量检索和模型，最后增加工具权限、日志和人工确认。不要从训练大模型开始，先把问题边界和失败样本记录好。

### 路线 D：只追前沿概念（约 5 小时）

`00 → 04 → 06 → 07 → 09 → 10`。这条路线会跳过推导，换取宽度；遇到“涌现、世界模型、量子优势”等词，务必回到本书的四问，不要把演示结果当成普遍能力。

## 四个贯穿母题

### 1. 表示的革命

机器不能直接处理“猫”“一张照片”或“今天下雨”这些概念，它需要数字表示。规则系统把概念写成符号，传统 NLP 把词统计成计数，神经网络把对象放进向量空间，Transformer 又让向量随上下文变化。

💡 **类比**：同一座城市可以用地铁线路图、卫星照片或地址簿表示。没有一种表示在所有任务上都最好；地图适合规划，照片适合识别，地址簿适合查找。读任何模型论文，先问它选择了哪一张“地图”。

### 2. 规模的力量

数据量、参数量、训练计算和推理时计算分别控制不同瓶颈。规模变大通常会降低训练损失，但能力是否有用还取决于数据质量、目标函数、评测和产品约束。长上下文也有成本：记得更多并不等于理解得更好。

### 3. 先验与数据的拔河

CNN 假定相邻像素相关，语言模型用因果顺序限制注意力，世界模型则假定环境有可预测的状态转移。先验减少了学习所需的数据，却可能把错误假设写进系统。结构越通用，越依赖数据；数据越少，越需要合适的结构。

### 4. 能力的代价

生成能力伴随幻觉，自动执行伴随权限风险，个性化伴随依赖，规模伴随能耗和集中化。安全不是正文末尾的装饰，而是每个设计选择的另一面。第十章会把这些代价翻译成可操作的控制。

## 从概念到项目的最小闭环

```
提出问题
  ↓
选择表示：关键词 / 向量 / 图像 patch / token
  ↓
选择学习方式：规则 / 监督学习 / 预训练 / 后训练
  ↓
运行模型：提示、检索、工具、采样
  ↓
验证结果：事实、鲁棒性、偏差、成本、延迟
  ↓
决定动作：交付、降级、人工确认或拒绝
```

模型回答只是中间产物。一个可靠系统还需要数据契约、权限边界、评测集、日志和退出按钮。

## 阅读方法与记笔记模板

每章建议只留下五类笔记：

1. **一句话机制**：它接收什么、计算什么、输出什么？
2. **一个先验**：模型默认相信世界的什么结构？
3. **一个规模旋钮**：数据、参数、上下文或测试时计算中哪一个最关键？
4. **一个失败样本**：什么时候会错，错了谁能发现？
5. **一个可复现实验**：不依赖昂贵 GPU，最好能在纸笔或 API 上完成。

⚠️ **不要把术语表当成绩单**：能背出“RLHF 的全称”不代表知道奖励模型解决什么问题。每个术语都要能放回上面的闭环，并能说出它的输入、输出和限制。

## 实验工具箱

你可以只用浏览器、电子表格和一台普通电脑完成全书大部分实验：

- 纸笔：手算感知机、卷积、TF-IDF、概率和量子幅度。
- 表格：画训练/验证曲线，做置信度校准，统计 token 成本。
- API：固定问题比较 temperature、top-p、提示模板和检索来源。
- 本地脚本：用少量文本实现词袋检索，再接一个只读工具。

🧪 **实验纪律**：固定变量、保存原始输出、记录日期和模型版本；把“无法判断”作为合法结果。没有对照组的演示只能说明“这次看起来有效”，不能说明方法普遍有效。

## 新手常问的五个问题

**一定要先学高等数学吗？** 不需要。先理解向量是数字列表、矩阵是批量变换、概率是对不确定性的刻度。等你知道某个公式解决什么问题，再补导数和线性代数，学习会更快。

**只看大模型一章够不够？** 可以得到名词地图，但容易把训练、推理、产品和治理混成一件事。至少配合第三章的表示和第十章的风险阅读。

**要不要自己训练一个模型？** 低资源阶段先做评测和检索原型。训练的价值在于理解数据与目标，不在于复刻商业模型的规模。

**为什么同一个模型每天回答不同？** 采样、系统提示、上下文、检索结果和模型版本都可能变化。可靠实验必须把这些条件记录下来。

**何时该停止自动化？** 当错误代价高、证据不足、权限不可逆或用户无法申诉时，把自动化降级为建议，并保留人工决策。
