# 第 3 章 自然语言处理

> **本章目标**：理解让机器处理人类语言的核心难题与解法演进。重点掌握三个里程碑式的思想跃迁：**词怎么变成数字**（词向量）、**上下文怎么被理解**（语言模型）、**知识怎么被大规模习得**（预训练范式）。这条路的终点就是大语言模型。

---

## 3.1 为什么语言对机器这么难

自然语言处理（Natural Language Processing, NLP）研究如何让计算机理解和生成人类语言。它被称为"人工智能皇冠上的明珠"——因为语言是人类智能最独特的载体，语言理解几乎等价于智能本身（图灵测试考的就是语言）。

难在哪？编程语言有严格语法、无歧义；自然语言处处是"坑"：

### 3.1.1 歧义无处不在

- **词汇歧义**：一词多义。"苹果发布会"vs"苹果三块钱一斤"；英文"bank"是银行还是河岸。
- **句法歧义**：结构可多解。"咬死了猎人的狗"——是（咬死了猎人）的狗，还是咬死了（猎人的狗）？英文经典例子："I saw a man with a telescope"——拿望远镜的是我还是那个男人？
- **指代歧义**："小王告诉小李他考上了"——"他"是谁？
- **语用歧义**：字面义 ≠ 真实意图。"你能把窗户关上吗？"不是在问能力，是请求。"你可真行啊"可能是夸奖也可能是讽刺。

人类靠**常识和语境**瞬间消歧，机器没有这些默认背景，每一步都是难题。

### 3.1.2 语言的其他挑战

- **组合爆炸**：有限词汇可组合出无限句子，绝大多数句子在任何语料库中从未出现过——不能靠背，必须靠泛化。
- **长距离依赖**："那个昨天在会上被经理点名批评的实习生**辞职了**"——主语和谓语隔了一长串修饰。
- **省略与隐含**："吃了吗？""吃了。"——吃什么、谁吃，全靠语境补全。
- **知识依赖**：理解"李白举杯邀明月"需要文学知识；理解"库里三分绝杀"需要体育知识。语言理解的尽头是世界知识。
- **中文特有难题**：词与词之间没有空格（"研究生命科学"是"研究/生命/科学"还是"研究生/命/科学"？），分词本身就是第一道关卡。

## 3.2 NLP 的经典任务地图

在"大一统"的大模型出现之前，NLP 被划分为许多独立任务，各自有专门模型。了解这张地图有助于理解 NLP 到底要解决什么：

| 层次 | 任务 | 说明与例子 |
|---|---|---|
| 词法层 | 分词 | 把句子切成词（中文尤其重要） |
| | 词性标注 | 名词/动词/形容词…… |
| | 命名实体识别（NER） | 找出人名、地名、机构名、时间 |
| 句法层 | 句法分析 | 分析句子的语法树结构 |
| 语义层 | 词义消歧 | "苹果"在此处指公司还是水果 |
| | 语义角色标注 | 谁（施事）对谁（受事）做了什么 |
| | 指代消解 | "他"指代前文哪个人 |
| 篇章/应用层 | 文本分类 | 垃圾邮件识别、情感分析、新闻分类 |
| | 信息抽取 | 从文本中抽取结构化信息（三元组） |
| | 机器翻译 | 中译英等 |
| | 自动摘要 | 长文压缩为短摘要 |
| | 问答系统 | 根据问题给出答案 |
| | 对话系统 | 多轮自然对话 |
| | 文本生成 | 写作、续写、改写 |

**一个重要的历史转折**：这些任务曾经"一个任务一个模型一支团队"；大语言模型出现后，**一个模型通过不同的提示语（prompt）就能完成几乎所有任务**——这个转变的技术脉络正是本章主线。

## 3.3 NLP 方法论的三个时代

### 3.3.1 规则时代（1950s–1980s）：语言学家写规则

思路：请语言学家把语法写成规则库。"名词短语 = 限定词 + 形容词* + 名词"，加上几万条词典和转换规则。

- 代表：早期机器翻译系统、ELIZA。
- 1954 年 Georgetown-IBM 实验用 250 个词、6 条语法规则演示俄译英，媒体轰动，预言"三五年解决机器翻译"。
- 结果：撞上歧义之墙。一个流传甚广的段子：把"心有余而力不足"（The spirit is willing but the flesh is weak）翻成俄语再翻回来，变成"伏特加不错但肉烂了"。1966 年美国 ALPAC 报告判定机器翻译失败，经费被砍——NLP 领域的第一次寒冬。
- 教训：**语言规则写不完，例外比规则多**。

### 3.3.2 统计时代（1990s–2000s）：数钱式的概率方法

思路转变：不问"这句话符合语法吗"，改问"**这句话出现的概率有多大**"。从大规模语料中统计规律。

标志性人物是 IBM 的贾里尼克（Frederick Jelinek），他有句（可能被演绎过的）名言："**我每解雇一个语言学家，语音识别的性能就上升一点。**"——粗暴但精准地概括了范式转移：领域知识让位于数据统计（"苦涩的教训"在 NLP 的预演）。

核心工具——**N-gram 语言模型**：

**语言模型（Language Model, LM）**的定义：计算一段文字出现概率的模型，等价于"给定前文，预测下一个词的概率分布"。这是 NLP 的中枢概念——**今天的 GPT 本质上仍然是语言模型**，这个定义贯穿始终，务必记住。

N-gram 用暴力统计实现语言模型：假设下一个词只依赖前面 N-1 个词（马尔可夫假设）：

```
P(我 爱 机器 学习) ≈ P(我) × P(爱|我) × P(机器|爱) × P(学习|机器)   ← 2-gram（只看前1个词）
其中 P(爱|我) = 语料中"我 爱"出现的次数 ÷ "我"出现的次数
```

应用：拼音输入法（"zhiwu"该出"植物"还是"职务"？看上下文哪个概率高）、拼写纠错、语音识别选字、早期统计机器翻译。

**N-gram 的天花板**：
1. **数据稀疏**：N 稍大（如 5），绝大多数词组合在语料中从未出现，概率为零（需各种平滑技巧硬补）。
2. **无泛化**：见过"猫在垫子上"不能推广到"狗在毯子上"——每个词是孤立符号，"猫"和"狗"毫无关联。
3. **窗口太短**：只看前几个词，长依赖完全丢失。

这三个缺陷，接下来的神经网络方法逐一击破。

### 3.3.3 神经网络时代（2010s 至今）

本章余下部分详述。先给整体脉络：

```
词向量（2013, Word2Vec）    → 词变成有语义的数字向量
   ↓
神经序列模型（2014–2017）   → RNN/LSTM 编码整句，seq2seq+注意力做翻译
   ↓
预训练语言模型（2018）      → ELMo/BERT/GPT：先读海量文本，再做具体任务
   ↓
大语言模型（2020–）         → 规模跃升,一个模型通吃所有任务（第 4 章）
```

## 3.4 词向量：意义的几何学

### 3.4.1 怎么把词变成数字

机器只认数字，第一个问题就是：词如何编码？

**朴素方案：独热编码（One-hot）**。词表有 5 万个词，每个词是一个 5 万维向量，属于自己的位置为 1，其余为 0：

```
猫 = [1, 0, 0, 0, ...]
狗 = [0, 1, 0, 0, ...]
汽车=[0, 0, 1, 0, ...]
```

致命缺陷：任何两个词的向量都互相垂直、距离相等——"猫"与"狗"的距离等于"猫"与"汽车"的距离。**语义信息完全丢失**。这正是 N-gram 无法泛化的根源。

**理想方案：分布式表示（Distributed Representation）**。把每个词表示为一个低维（如 300 维）**稠密**实数向量，让**语义相近的词在向量空间中彼此靠近**：

```
猫 = [0.21, -0.45, 0.91, ...]      猫·狗 相似度高
狗 = [0.19, -0.40, 0.88, ...]      猫·汽车 相似度低
汽车=[-0.83, 0.66, 0.02, ...]
```

这样的向量称为**词向量 / 词嵌入（Word Embedding）**——"嵌入"意为把离散符号嵌入到连续几何空间。

### 3.4.2 分布假说：意义来自语境

凭什么能学出这种向量？语言学家 Firth（1957）的**分布假说（Distributional Hypothesis）**：

> "You shall know a word by the company it keeps."（观其伴而知其义。）

**一个词的意义由它的上下文分布决定**。"猫"和"狗"语义相近，因为它们出现的语境相似（都常和"喂、宠物、毛、叫"共现）。你甚至能靠这个学会不认识的词：多次见到"他端起一杯 X，抿了一口，微醺"——即使从没人告诉你 X 是什么，你也知道它是种酒。

这是整个现代 NLP 的哲学地基：**不定义意义，而从使用中统计意义**。大模型对语言的全部"理解"都源于此。

### 3.4.3 Word2Vec（2013）：里程碑

谷歌的 Mikolov 团队提出 Word2Vec，用一个极简的神经网络高效学习词向量。两种训练方式：

- **Skip-gram**：用中心词预测周围词。给"机器"，预测上下文可能出现"学习、深度、算法"。
- **CBOW**：反过来，用周围词预测中心词。

训练本质：海量文本滑窗扫过，不断调整词向量，使"共现的词向量相近"。**没有任何人工标注**——这是自监督学习的早期典范。

**震撼学界的发现——词向量支持语义算术**：

```
vec(国王) - vec(男人) + vec(女人) ≈ vec(女王)
vec(巴黎) - vec(法国) + vec(中国) ≈ vec(北京)
vec(walked) - vec(walk) + vec(swim) ≈ vec(swam)
```

性别、首都关系、时态这些抽象概念，竟自发地对应了向量空间中的**方向**。这是"神经网络能从原始文本中学到结构化知识"的第一个强证据。同期还有斯坦福的 GloVe 等变体。

**词向量的实际意义**：作为下游任务的输入层，所有 NLP 任务的性能普涨——因为模型见到"狗"时自动获得了与"猫"相关的知识。泛化问题被根本性改善。

### 3.4.4 静态词向量的局限

Word2Vec 每个词**只有一个固定向量**。但"苹果"在"苹果股价"和"苹果真甜"里意思不同！静态向量只能把多个词义"平均"成一个混合向量。

解法显而易见又很难做到：**根据上下文动态生成词的表示**——同一个词在不同句子里有不同向量。这就是**上下文相关表示（contextualized representation）**，由 2018 年的 ELMo 首次实用化，并直通 BERT/GPT。技术条件是需要一个强大的序列编码器——于是回到第 2 章讲过的 RNN 与 Transformer。

## 3.5 神经语言模型与 seq2seq

### 3.5.1 神经语言模型

用神经网络实现语言模型（预测下一个词），可以同时解决 N-gram 的三大缺陷：

- 词用词向量表示 → 相似词共享统计强度 → **泛化**（见过"猫在垫子上"，对"狗在毯子上"也能给高概率）。
- RNN 的隐状态可携带任意长的前文 → **长依赖**。
- 稠密向量空间中无"没见过就是零" → **稀疏问题消失**。

Bengio 2003 年就提出了神经语言模型，但算力不足，直到 2010 年代 RNN/LSTM 成熟才成为主流。

### 3.5.2 seq2seq：编码器-解码器框架

2014 年的**序列到序列（seq2seq）**框架解决"输入一个序列、输出另一个序列"的任务（翻译、摘要、对话）：

```
输入"我爱机器学习" → [编码器RNN] → 语义向量 → [解码器RNN] → 输出 "I love machine learning"
```

- **编码器（Encoder）**：读入整句，压缩成一个向量（"理解"）。
- **解码器（Decoder）**：从该向量出发，逐词生成目标句（"表达"）。

**瓶颈**：整句话压进一个固定长度向量，句子一长信息就装不下——如同要求翻译员听完三分钟演讲后，仅凭一个模糊的总体印象完整复述。

### 3.5.3 注意力机制的诞生（2014–2015）

Bahdanau 等人的解法：解码器生成每个词时,**回头去看编码器的全部输出，按相关性加权取用**。翻译"learning"这个词时，注意力权重集中在"学习"上。

这就是**注意力机制**的起源——先作为 seq2seq 的补丁诞生（2014），三年后被 Transformer 扶正为唯一主角（2017，"Attention Is All You Need"的标题正是对此的宣言）。第 2 章已讲过其原理，此处看到了它的历史脉络。

2016 年谷歌翻译全面切换神经机器翻译（GNMT），翻译质量一夜之间大幅跃升，是深度学习 NLP 第一个"出圈"的胜利。

### 3.5.4 分词的现代解法：子词

顺带解决一个工程问题：词表怎么定？按完整词建表，词表巨大且永远有生词（OOV, out-of-vocabulary）；按字符建表，序列太长且单字符无义。

现代方案：**子词切分（subword tokenization）**，如 **BPE（Byte Pair Encoding）**算法——从字符开始，反复合并语料中最高频的相邻单元，得到一个介于字符和词之间的词表：

```
"unhappiness" → "un" + "happi" + "ness"
"ChatGPT很好用" → "Chat" + "G" + "PT" + "很" + "好用"
```

- 常见词保持完整（高效），生僻词拆成碎片（永不 OOV）。
- 这些单元称为 **token（词元）**——大模型按 token 计费、按 token 计算上下文长度，根源就在这里。一个 token 平均约 0.75 个英文单词或 0.5~0.7 个汉字。
- 大模型的一些奇怪短板（数不清"strawberry"里有几个 r、算术容易错位）部分源于 token 化：模型看到的不是字母/数字序列，而是切碎的 token。

## 3.6 预训练革命：NLP 的"ImageNet 时刻"

### 3.6.1 范式转移

2018 年前的 NLP：每个任务从头训练专用模型，需要大量该任务的标注数据（贵且少）。

2018 年起的新范式：**预训练 + 微调（Pre-train + Fine-tune）**：

1. **预训练**：在海量无标注文本（维基百科、网页、书籍）上用自监督目标训练大模型——学到词汇、语法、事实知识、部分推理能力。
2. **微调**：用少量标注数据在具体任务上继续训练几轮，把通用语言能力对准该任务。

类比：先让学生读完整个图书馆（预训练获得通识），再做一薄册习题（微调对准考试）——完胜从零只刷题的学生。

自监督目标不要人工标注，所以**训练数据近乎无限**——互联网就是语料库。数据瓶颈被打开，规模竞赛的闸门由此拉开。

### 3.6.2 双雄：BERT 与 GPT

2018 年,两个基于 Transformer 的预训练模型同年问世，代表两条路线：

**GPT（OpenAI，2018.6）——只用 Transformer 解码器,自回归语言模型**

- 训练目标：**预测下一个词**（从左到右）。"床前明月__" → "光"。
- 单向：只能看左侧上文（生成时也只有上文可看）。
- 天然擅长**生成**。

**BERT（谷歌，2018.10）——只用 Transformer 编码器,掩码语言模型**

- 训练目标：**完形填空**（Masked LM）——随机遮住句中 15% 的词，让模型根据**双向**上下文猜。"床前[MASK]月光，疑似地上霜" → "明"。
- 双向：同时看左右语境，理解更充分。
- 天然擅长**理解**类任务（分类、抽取、匹配）。

BERT 发布时横扫 11 项 NLP 基准测试记录,引爆学术界；2019 年起 BERT 类模型进入谷歌搜索、各大厂 NLP 生产线，统治工业界理解类任务数年。

**历史的转折**：当时多数人押注 BERT 路线（理解任务基准上分数更高）。但 OpenAI 坚持 GPT 路线并持续扩大规模——GPT-2（2019, 15 亿参数）、GPT-3（2020, 1750 亿参数）。事后看,生成路线赢得了未来，原因深刻：

1. **生成天然涵盖理解**：任何任务都可以转写成文本生成——"这句话的情感是？答：正面"。理解模型却做不了生成。
2. **预测下一个词是终极压缩任务**：要预测好任意文本的下一个词，模型被迫学会语法、事实、逻辑、甚至心理——"预测即理解"。
3. **自回归目标与规模的配合更好**（每个 token 都提供训练信号,数据利用率高）。

第 4 章从这里接续：当 GPT 式模型大到一定程度，质变发生了。

### 3.6.3 提示学习：不训练也能用

GPT-3 展示了第三种使用模型的方式——不微调，**直接用自然语言指令和示例驱动模型**：

- **零样本（Zero-shot）**：直接下指令。"把下面这句话翻译成英文：……"
- **少样本（Few-shot）/ 上下文学习（In-context Learning）**：给几个示例，模型现场"领悟"任务模式：

```
输入：这部电影太精彩了 → 正面
输入：浪费了我两小时  → 负面
输入：演员演技在线,剧情一般 → ?
```

模型**没有更新任何权重**，仅凭上下文中的模式就完成了任务。这一能力事先无人预料，是从规模中**涌现**出来的（涌现现象详见第 4 章）。

于是范式再次演化：

```
2018 前：  一个任务 = 一个模型 + 一批标注数据（从头训练）
2018–2020：一个任务 = 预训练模型 + 少量标注微调
2020 后：  一个模型 + 不同提示词 = 所有任务（Prompt 时代）
```

"写提示词"（Prompt Engineering）取代"训模型"成为多数使用者与 NLP 打交道的方式——NLP 的门槛从博士学位降到会打字。这是技术民主化的巨大跨越，也正是 ChatGPT 能够引爆大众的原因。

## 3.7 NLP 任务的现状：大一统之后

大模型时代，第 3.2 节那张任务地图发生了什么？

- **多数经典任务被"归一"**：翻译、摘要、情感分析、问答、NER……用一个大模型加提示词即可达到或超过专用模型，专用模型仅在延迟/成本敏感或垂直高精度场景保留。
- **中间任务消亡**：词性标注、句法分析这些"为下游服务"的中间任务失去独立意义——大模型内部隐式地学会了它们（探针实验显示 BERT/GPT 的中间层编码了句法树信息）。
- **新任务诞生**：提示工程、长文档处理、检索增强生成（RAG，让模型先查资料再回答）、工具调用、幻觉检测、对齐评估——NLP 的研究前沿转向"如何用好/管好大模型"。
- **评测危机**：老基准（GLUE 等）被刷满,新基准（MMLU、考试题、人类对战排名）不断被追赶,"怎么科学评价语言能力"重新成为难题（第 4 章展开）。

**一句话总结这条主线**：NLP 七十年，是一部"人工规则 → 人工特征+统计 → 自动特征+神经网络 → 自动学会一切"的**人类退出史**——人的先验知识逐步让位于数据与算力，最终在语言模型这个统一目标上完成大一统。

## 3.8 本章小结

1. 语言难在**歧义、组合爆炸、语境依赖与世界知识**——规则永远写不完，这决定了统计与学习路线的最终胜利。
2. **语言模型 = 预测下一个词的概率**。这个概念从 N-gram 一路贯穿到 GPT，是 NLP 的中枢。
3. **分布假说**（观其伴而知其义）是意义的统计学定义；**Word2Vec** 用它把词变成了有语义几何的向量（国王-男人+女人≈女王），根本性解决了符号表示无泛化的问题。
4. 静态词向量无法处理一词多义 → 需要**上下文相关表示** → 由强序列编码器（RNN→Transformer）实现。
5. **seq2seq**（编码器-解码器）解决序列变换任务；**注意力机制**先是其补丁（2014），后成 Transformer 的全部（2017）。
6. **子词切分（BPE/token）**解决词表与生词问题；token 是大模型计量与部分怪异短板的根源。
7. **预训练+微调**范式（2018, BERT/GPT）打开无标注数据的闸门；**BERT（双向理解）与 GPT（单向生成）**两条路线中，生成路线因"生成涵盖理解、预测即压缩"而最终胜出。
8. GPT-3 的**上下文学习**开启 Prompt 时代：一个模型+不同提示=所有任务。NLP 从此进入大模型纪元——下一章正式进入大语言模型。
