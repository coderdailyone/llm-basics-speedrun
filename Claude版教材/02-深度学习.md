## 2.1 从机器学习说起

### 2.1.1 换一种编程方式

传统编程：人写规则，机器执行。

```
规则 + 数据 → 答案       （传统编程）
数据 + 答案 → 规则       （机器学习）
```

举例：写一个识别垃圾邮件的程序。
- **传统方式**：人工总结规则——"包含'中奖'就标记""发件人不在通讯录且含链接就标记"……规则永远写不完，垃圾邮件发送者稍微变个花样就绕过了。
- **机器学习方式**：给机器 10 万封已标注"垃圾/正常"的邮件，让它**自己**找出区分两者的统计规律。规律不是人写的代码，而是一堆学出来的**参数**。

### 2.1.2 机器学习的三种范式

按"学习信号从哪来"分类：

1. **监督学习（Supervised Learning）**：数据带标准答案（标签）。给图片和"猫/狗"标签，学习分类；给房屋信息和成交价，学习回归预测。**目前工业界应用最广**。
   - 分类（离散输出）：垃圾邮件识别、图像识别
   - 回归（连续输出）：房价预测、温度预测
2. **无监督学习（Unsupervised Learning）**：数据没有标签，让机器自己发现结构。聚类（把用户分群）、降维（把高维数据压到低维）、密度估计。
   - 重要变体——**自监督学习（Self-supervised Learning）**：从数据自身构造监督信号。比如遮住句子里的一个词让模型猜（BERT），或让模型预测下一个词（GPT）。**这是大模型成功的基石**——不需要人工标注，互联网上的所有文本天然就是训练数据。
3. **强化学习（Reinforcement Learning, RL）**：没有标准答案，只有**奖励信号**。智能体在环境中试错，逐渐学会最大化累积奖励的策略。AlphaGo 下棋、机器人控制、大模型对齐（RLHF）都用它。

一个常用类比（来自 Yann LeCun 的"蛋糕说"）：如果智能是一块蛋糕，自监督学习是蛋糕坯（信息量最大），监督学习是糖霜，强化学习是顶上的樱桃（信号最稀疏但关键）。

### 2.1.3 机器学习的基本流程

无论哪种范式，训练一个模型的流程大同小异：

```
收集数据 → 划分数据集 → 选择模型 → 定义损失函数 → 优化（训练） → 评估 → 部署
```

**数据集划分**是新手最容易忽视的关键点：

- **训练集（training set）**：模型学习用。
- **验证集（validation set）**：调超参数、选模型用。
- **测试集（test set）**：最终评估用，**只能用一次**，绝不能参与任何训练决策。

为什么这么严格？因为机器学习的目标不是"记住训练数据"，而是**泛化（generalization）**——在没见过的数据上表现好。如果用测试集调参，等于考试前偷看了考卷，成绩就失去意义。这个错误在学界和业界都反复发生（称为"数据泄漏"）。

## 2.2 神经网络：从一个神经元开始

### 2.2.1 人工神经元

生物神经元的工作方式：接收多个树突传来的信号，加权汇总，超过阈值就"点火"，通过轴突输出。1943 年 McCulloch-Pitts 模型将其抽象为数学形式：

```
输入 x₁, x₂, ..., xₙ
       │
       ▼
  加权求和：z = w₁x₁ + w₂x₂ + ... + wₙxₙ + b
       │
       ▼
  激活函数：a = f(z)
       │
       ▼
      输出 a
```

用文字说：**一个神经元 = 加权求和 + 一个非线性函数**。

- **权重 w（weight）**：每个输入的重要程度。学习，就是调整这些权重。
- **偏置 b（bias）**：调整触发的难易程度（阈值的负数）。
- **激活函数 f**：引入非线性（下面细说）。

举个直觉例子：判断"今天要不要出门跑步"。输入是温度 x₁、是否下雨 x₂、昨晚睡眠时长 x₃。你脑中对三者的重视程度就是权重；"综合打分超过某个心理阈值就去跑"就是激活。

### 2.2.2 为什么需要激活函数

如果没有激活函数（或激活函数是线性的），多层网络无论叠多少层，数学上都等价于一层线性变换——因为线性函数的复合还是线性函数。而线性模型连"异或"这种简单模式都学不会（第 1 章提到的《感知机》批判）。

**非线性激活函数让网络能拟合任意复杂的函数**。这是"通用近似定理"（Universal Approximation Theorem）保证的：一个足够宽的单隐层网络配非线性激活，理论上可以以任意精度逼近任何连续函数。

常见激活函数：

| 名字 | 公式 | 特点 |
|---|---|---|
| Sigmoid | 1/(1+e⁻ᶻ) | 输出压缩到 (0,1)，早期常用，深层网络中会导致梯度消失，现在主要用于输出层表示概率 |
| Tanh | 双曲正切 | 输出 (-1,1)，零中心化，同样有梯度消失问题 |
| **ReLU** | max(0, z) | 大于 0 原样输出，小于 0 输出 0。计算极快，缓解梯度消失，**深度学习时代的默认选择** |
| GELU / SiLU | ReLU 的平滑版 | Transformer 和现代大模型的常用选择 |
| Softmax | 归一化指数 | 用于多分类输出层，把一组分数变成总和为 1 的概率分布 |

ReLU 看上去简单得可笑——就是"负数归零"——但正是它在 2012 年前后的普及大幅缓解了深层网络的训练困难。**深度学习史上多次出现"简单的东西反而有效"**。

### 2.2.3 从神经元到网络

把神经元分层排列，前一层的输出作为后一层的输入，就得到**多层感知机（MLP, Multi-Layer Perceptron）**，也叫全连接网络：

```
输入层        隐藏层1      隐藏层2      输出层
 x₁ ──┐      ○            ○
 x₂ ──┼──►   ○     ──►    ○     ──►    ○  →  预测值
 x₃ ──┘      ○            ○
             ○
（每条连线都是一个可学习的权重）
```

- **输入层**：原始数据（图片像素、文本编码后的数字等）。
- **隐藏层**：中间的计算层。"深度"学习的"深"，指的就是隐藏层多。
- **输出层**：给出预测（分类概率、回归数值等）。

**"深"为什么重要？** 理论上单隐层就能逼近任何函数，但可能需要指数级多的神经元。深层网络的优势在于**分层抽象**：底层学简单特征，高层把简单特征组合成复杂特征。以人脸识别为例，可视化研究发现：

```
第1层：边缘、颜色斑块（横线、竖线、斜线）
第2层：简单形状（角、弧、纹理）
第3层：部件（眼睛、鼻子、嘴的雏形）
高层 ：完整的脸部结构
```

这与生物视觉皮层的分层处理惊人地相似。**特征不再需要人工设计，而是逐层自动涌现**——这是深度学习相对于传统机器学习最本质的进步。传统机器学习时代，工程师 80% 的时间花在"特征工程"（人工设计输入特征）上；深度学习把这一步交给了网络自己。

## 2.3 学习的本质：损失函数与梯度下降

现在到了最核心的问题：**权重是怎么"学"出来的？**

### 2.3.1 损失函数：量化"错得多离谱"

要改进，先要能衡量好坏。**损失函数（Loss Function）**把"模型预测与正确答案的差距"量化为一个数字，数字越小越好。

- **回归任务**常用**均方误差（MSE）**：预测值与真实值之差的平方的平均。预测房价 500 万、实际 480 万，误差 20 万，平方后计入损失。
- **分类任务**常用**交叉熵（Cross-Entropy）**：衡量预测概率分布与真实分布的差距。模型说"这张图 90% 是猫"而它确实是猫，损失很小；说"10% 是猫"，损失很大。大语言模型预测下一个词，用的就是交叉熵。

于是"学习"被转化为一个纯数学问题：**找到一组权重，使损失函数在训练数据上最小**。这叫**优化问题**。

### 2.3.2 梯度下降：下山的艺术

想象损失函数是一片崇山峻岭（横轴是权重的取值，纵轴是损失），你被蒙着眼扔在山上某处，任务是走到谷底。你能做的：**用脚感受当前位置哪个方向最陡峭地向下，朝那个方向迈一小步，反复**。

这就是**梯度下降（Gradient Descent）**：

```
新权重 = 旧权重 - 学习率 × 梯度
```

- **梯度（gradient）**：损失函数对每个权重的导数，指向损失上升最快的方向。取负号就是下降最快的方向。
- **学习率（learning rate）**：每步迈多大。**深度学习中最重要的超参数**。太大：一步跨过谷底，甚至越走越高（训练发散）；太小：磨磨蹭蹭，训练极慢，还可能卡在浅坑里。

实践中的变体：

- **随机梯度下降（SGD）**：每次不用全部数据算梯度（太慢），而是随机抽一小批（mini-batch，如 32~几百万个样本）估算。省算力，且噪声反而有助于跳出差的局部低谷。
- **动量（Momentum）**：模拟惯性，像滚下山的球，累积历史方向，冲过小坑洼。
- **Adam / AdamW**：为每个参数自适应调节学习率，收敛快且省心，**当前训练大模型的默认优化器**（AdamW 是修正了权重衰减实现的版本）。

### 2.3.3 反向传播：高效计算梯度

一个大模型有数十亿到数万亿个权重，怎么高效算出损失对**每一个**权重的梯度？答案是**反向传播算法（Backpropagation）**——1986 年 Rumelhart、Hinton、Williams 推广的方法，深度学习的算法基石。

核心思想只是微积分的**链式法则**：复合函数的导数等于各层导数的乘积。

直觉版解释：网络前向计算像流水线——原料（输入）经过一道道工序（每层）变成产品（输出），质检发现产品不合格（损失高）。反向传播就是**从最后一道工序往前逐级追责**："输出错了 3 分，其中最后一层的权重 A 贡献了多少？倒数第二层的权重 B 通过影响 A 的输入又间接贡献了多少？"逐层回传，每个权重都分到一份"责任"（梯度），然后按责任大小调整自己。

完整的训练循环：

```
重复直到收敛：
  1. 前向传播：输入数据，逐层计算，得到预测
  2. 计算损失：预测 vs 真实答案
  3. 反向传播：链式法则逐层回传，算出每个权重的梯度
  4. 更新权重：权重 -= 学习率 × 梯度
```

大模型训练几个月，本质上就是这四步循环了几百万次。

### 2.3.4 梯度消失与梯度爆炸

反向传播中梯度要逐层**连乘**。层数一深，问题就来了：

- 每层的局部梯度普遍小于 1 → 连乘后指数级缩小 → **梯度消失**：靠前的层几乎收不到学习信号，等于没在训练。
- 每层的局部梯度普遍大于 1 → 连乘后指数级放大 → **梯度爆炸**：权重更新剧烈震荡，训练崩溃。

这曾是"网络做不深"的根本原因。解决方案是一系列工程创新的组合拳：

1. **ReLU 激活**：正区间导数恒为 1，不衰减。
2. **合理的权重初始化**（Xavier/He 初始化）：让各层信号方差保持稳定。
3. **归一化层**：BatchNorm（CNN 时代）/ **LayerNorm**（Transformer 时代），把每层的输入拉回稳定分布。
4. **残差连接（Residual Connection）**：ResNet（2015）的革命性设计——每层不再直接学输出，而是学"输出与输入的差"，即 `输出 = F(输入) + 输入`。那条把输入直接加到输出的"捷径"，给梯度提供了一条无衰减的高速公路。**有了残差连接，网络才真正做到了几百上千层**。今天每个 Transformer 块里都有它。

## 2.4 过拟合：背题家的陷阱

### 2.4.1 什么是过拟合

模型在训练集上表现极好、在新数据上表现糟糕，叫**过拟合（Overfitting）**。类比：学生把练习册的答案全背下来了，练习册满分，高考换了题就完蛋——他记住了题目，没学会方法。

反面是**欠拟合（Underfitting）**：模型太简单，连训练集都学不好，如同用直线去拟合波浪形数据。

判断方法：对比训练集与验证集的损失曲线。

```
损失
 │\
 │ \  ←验证集损失：先降后升（升起点=开始过拟合）
 │  \___╱⌒⌒
 │   \
 │    \______  ←训练集损失：持续下降
 └──────────────► 训练轮数
```

### 2.4.2 对抗过拟合的武器库

1. **更多数据**：最根本的解法。数据多到背不完,就只能学规律。
2. **数据增强（Data Augmentation）**：免费扩充数据——图片翻转/裁剪/变色，文本回译等。
3. **正则化（Regularization）**：在损失函数中惩罚过大的权重（L1/L2 正则），逼模型保持"简洁"。
4. **Dropout**：训练时每步随机"关闭"一部分神经元（如 10–50%），逼网络不依赖任何单个神经元，学出冗余而稳健的表示。类比：球队训练时随机让主力休息，逼替补成长。
5. **早停（Early Stopping）**：验证集损失开始回升就停止训练。
6. **减小模型**：参数少了，背不动了。

### 2.4.3 深度学习的反直觉之处

经典统计直觉：模型参数越多越容易过拟合。但深度学习出现了违反直觉的现象——**参数远多于数据量的超大模型，泛化反而更好**（"双下降"现象、过参数化之谜）。大语言模型有万亿参数，理论上足以背下全部训练数据，但它们展现出强大的泛化能力。为什么？这仍是深度学习理论的开放问题，主流解释方向包括：SGD 隐式偏好"平坦"的极小值、过参数化让优化景观更平滑等。**记住这个事实：深度学习的实践跑在理论前面，很多"为什么有效"至今没有严格答案。**

## 2.5 三代经典架构

全连接网络对什么数据都"一视同仁"，但真实数据有结构：图像有空间局部性，语言有顺序。针对数据结构设计的架构，效率远高于通用结构。这就是**归纳偏置（inductive bias）**——把对数据的先验知识内建到网络结构中。

### 2.5.1 卷积神经网络（CNN）：为图像而生

**动机**：一张 1000×1000 的彩色图有 300 万个像素，全连接第一层就要天文数字的参数；且图像的关键规律是**局部的**（猫耳朵只占图片一角）和**平移不变的**（猫在左上角还是右下角都是猫）。

**卷积（Convolution）**的解法：用一个小窗口（卷积核，如 3×3）在图像上滑动，每个位置做加权求和，输出一张"特征图"。

```
输入图像            3×3卷积核        特征图
┌─────────┐         ┌───┐          ┌───────┐
│ ▒▒▒▒▒▒▒ │   ←滑动─ │ w │  ──►    │ 检测到 │
│ ▒▒▒▒▒▒▒ │         └───┘          │ 边缘的 │
│ ▒▒▒▒▒▒▒ │                        │ 位置图 │
└─────────┘                        └───────┘
```

两大设计精髓：
- **局部连接**：每个输出只看输入的一小块（感受野），符合"图像特征是局部的"。
- **权重共享**：同一个卷积核扫全图，一个核只有 9 个参数（3×3），却处理了整张图。参数量骤降，且天然获得平移不变性——检测"竖直边缘"的核在哪里都能检测。

典型 CNN 结构：`[卷积→激活→池化] × N → 全连接 → 输出`。**池化（Pooling）**是降采样（如取 2×2 区域的最大值），缩小尺寸、扩大感受野、增加稳健性。

里程碑：
- **LeNet**（1998，LeCun）：识别手写数字，商用于银行支票。
- **AlexNet**（2012）：ImageNet 夺冠，点燃深度学习革命。
- **VGG**（2014）：证明"深"的价值，统一用 3×3 小核。
- **ResNet**（2015，何恺明等）：残差连接，深度冲到 152 层+，ImageNet 错误率首次超过人类水平。**深度学习史上引用量最高的论文之一**。

### 2.5.2 循环神经网络（RNN）：为序列而生

**动机**：语言、语音、股价是**序列**——长度不定，且当前词的含义依赖前文。CNN 和 MLP 都要求固定长度输入，不合适。

**RNN 的解法**：一个循环单元逐步读取序列，并维护一个**隐状态（hidden state）**作为"记忆"：

```
       h₀ ──► h₁ ──► h₂ ──► h₃ ──► ...   （记忆随时间传递）
       ▲      ▲      ▲      ▲
       │      │      │      │
      x₁     x₂     x₃     x₄            （逐个读入：我 / 爱 / 机器 / 学习）
```

每一步：`新记忆 = f(旧记忆, 当前输入)`。同一套权重反复使用，天然处理任意长度。

**RNN 的两大顽疾**：
1. **长程依赖难学**：反向传播要沿时间步连乘（BPTT），序列一长梯度就消失——"句子开头的信息传不到结尾"。
2. **无法并行**：必须算完第 t 步才能算第 t+1 步，训练慢，吃不下大数据。

**LSTM（长短期记忆网络，1997）**用"门控"机制缓解第一个问题：引入专门的细胞状态（长期记忆传送带）和三个门——**遗忘门**（丢掉哪些旧记忆）、**输入门**（写入哪些新信息）、**输出门**（读出哪些记忆）。门是可学习的 0~1 开关。LSTM 及其简化版 **GRU** 统治了 2014–2017 年的 NLP（机器翻译、语音识别）。

但第二个问题（无法并行）是结构性的，无解。这为 Transformer 的登场埋下伏笔。

### 2.5.3 Transformer：注意力就是一切

2017 年，谷歌论文《Attention Is All You Need》提出 Transformer，彻底抛弃循环结构，只用**注意力机制（Attention）**处理序列。

**注意力的直觉**：理解句子"银行旁边的苹果店挤满了人，**它**的新手机今天发售"中的"它"指什么，你的目光会自动回扫并锁定"苹果店"而不是"银行"。注意力机制就是让**序列中的每个位置直接"看"所有其他位置，并按相关性加权汇总信息**。

**自注意力（Self-Attention）**的计算（概念版）：每个词生成三个向量——
- **Query（查询）**：我在找什么？
- **Key（键）**：我是什么（供别人匹配）？
- **Value（值）**：我实际携带的信息。

每个词拿自己的 Q 与所有词的 K 算相似度 → softmax 归一化成注意力权重 → 按权重对所有词的 V 加权求和 → 得到该词融合了上下文的新表示。类比：在图书馆检索（Q=检索词，K=书脊标签，V=书的内容），按匹配度把相关书籍的内容加权融合。

**相对 RNN 的两大杀手优势**：
1. **任意两个位置直接相连**：第 1 个词和第 1000 个词之间的信息通路长度是 1，不再有随距离衰减的记忆——长程依赖问题釜底抽薪。
2. **完全并行**：整个序列的注意力可以表达为几个大矩阵乘法，一次算完——完美匹配 GPU，训练速度和可扩展性发生质变。**Transformer 能吃下互联网级别的数据，这是大模型得以出现的架构前提。**

代价：注意力计算量与序列长度的平方成正比（每个词看所有词），长文本昂贵——这是后续无数优化（稀疏注意力、FlashAttention 等，见第 4 章）要解决的问题。

Transformer 块的标准配方（记住这个,第 4 章会展开）：

```
输入 → [多头自注意力 → 残差+LayerNorm → 前馈网络(MLP) → 残差+LayerNorm] × N层 → 输出
```

- **多头（Multi-Head）**：并行跑多组注意力，每组关注不同类型的关系（有的头盯语法、有的头盯指代）。
- **位置编码（Positional Encoding）**：注意力本身不感知顺序（打乱输入词序结果不变），需额外注入位置信息。

**三代架构对比总结**：

| | MLP | CNN | RNN/LSTM | Transformer |
|---|---|---|---|---|
| 擅长数据 | 表格 | 图像 | 序列 | 序列（及一切） |
| 归纳偏置 | 无 | 局部性、平移不变 | 顺序、时间递归 | 极弱（靠数据学） |
| 并行性 | 好 | 好 | 差 | 极好 |
| 长程依赖 | — | 需堆层 | 弱 | 强 |
| 代表应用 | 简单预测 | 图像识别 | 早期翻译/语音 | 大语言模型、一切 |

一个重要趋势：**Transformer 正在"吞噬"其他架构的领地**——图像（ViT，第 5 章）、语音、蛋白质、多模态（第 6 章）都在 Transformer 化。归纳偏置弱意味着"少做假设、多靠数据"，在大数据时代反而成了优势——再次呼应"苦涩的教训"。

## 2.6 训练深度网络的工程实践

理论之外，深度学习是一门实验科学。实际训练一个模型时的核心操作和概念：

### 2.6.1 超参数

模型自己学的叫**参数**（权重）；人为设定的叫**超参数（hyperparameter）**：学习率、批大小（batch size）、层数、每层宽度、训练轮数（epoch）、Dropout 比例……调超参数（炼丹）是深度学习工程师的日常。经验法则：**学习率永远是第一个要调的**。常配合**学习率调度**：先热身（warmup，从小到大）再衰减（如余弦衰减）——大模型训练的标配。

### 2.6.2 硬件与框架

- **GPU 为什么快**：神经网络 90%+ 的计算是矩阵乘法，GPU 有数千个核心并行做乘加运算。CPU 是几位数学教授，GPU 是一千个只会算乘法的小学生——算矩阵乘法后者完胜。
- **主流框架**：**PyTorch**（研究界与大模型界的事实标准）、TensorFlow/JAX（谷歌系）。框架的核心能力是**自动微分（autograd）**——你只写前向计算，反向传播自动完成。
- **混合精度训练**：用 16 位浮点数（FP16/BF16）代替 32 位做大部分计算，速度翻倍、显存减半，是大模型训练标配。

### 2.6.3 迁移学习与微调

从零训练大网络又贵又需海量数据。**迁移学习（Transfer Learning）**：拿在大数据集上**预训练（pre-train）**好的模型，在自己的小数据集上**微调（fine-tune）**。预训练模型已学会通用特征（视觉的边缘纹理、语言的语法常识），微调只需教它领域细节。

这个"预训练 + 微调"范式先在 CV 兴起（在 ImageNet 上预训练），后被 NLP 发扬光大（BERT/GPT），最终演化为大模型时代的基本格局：**少数机构烧巨资预训练基础模型，其他人微调或直接调用**。（详见第 3、4 章。）

## 2.7 本章小结

1. 机器学习 = 从数据中学规律。三大范式：**监督、无监督（含自监督）、强化学习**。自监督学习是大模型的基石。
2. 神经网络的基本单元 = **加权求和 + 非线性激活**；深层网络的力量在于**逐层自动抽象特征**，取代了人工特征工程。
3. 学习的数学本质：**用梯度下降最小化损失函数**；梯度靠**反向传播**（链式法则）高效计算。整个深度学习的训练就是"前向算损失、反向传梯度、更新权重"的循环。
4. 深层网络曾因**梯度消失/爆炸**难以训练，被 ReLU、归一化、**残差连接**等创新解决。
5. **过拟合**是"背题"而非"学习"；用更多数据、正则化、Dropout、早停对抗。超大模型泛化良好的原因至今没有完整理论——实践跑在理论前面。
6. 三代架构的演进逻辑：**CNN**（局部性+权重共享,为图像）→ **RNN/LSTM**（记忆传递,为序列,但难并行）→ **Transformer**（注意力直连一切位置+完全并行,为大规模而生）。
7. Transformer 的并行性使其能消化互联网级数据，**是大模型出现的架构前提**——第 4 章将深入其内部。
