# 第 5 章 计算机视觉

> **本章目标**：理解机器如何"看"。从像素矩阵到语义理解的完整链条：视觉为什么难、CNN 王朝的兴衰、检测/分割等核心任务的解法思想、Vision Transformer 的统一之势，以及扩散模型如何学会画画。
>
> 前置知识：第 2 章的 CNN 与 Transformer。

---

## 5.1 机器眼中的图像

### 5.1.1 图像就是数字矩阵

对机器而言，一张图片没有"猫"没有"天空"，只有一个数字网格：

- **灰度图**：一个 H×W 的矩阵，每个元素是 0（黑）~255（白）的亮度值。
- **彩色图**：三个矩阵叠放（RGB 三通道），形状 H×W×3。一张 1080p 照片 ≈ 600 万个数字。
- **视频**：再加一个时间维度,T×H×W×3。

**计算机视觉（Computer Vision, CV）**的任务就是：从这堆数字里恢复出"这是什么、在哪里、在发生什么"。

### 5.1.2 为什么"看"这么难

人类视觉毫不费力（大脑约 1/3 皮层在处理视觉,亿万年进化的结晶——回忆莫拉维克悖论），但对机器：

- **语义鸿沟**：像素值与语义之间没有直接对应。两张"猫"的照片,像素层面可能天差地别;一张猫和一张猫玩偶,像素层面可能极其相似。
- **万变的成像条件**：同一只猫,换个光照、角度、距离、姿态、遮挡一半躲在沙发后,像素全变了,但语义没变。视觉系统必须对这一切**不变**。
- **背景干扰**：真实照片里目标只占一角,大部分像素是无关背景。
- **类内差异大于类间差异**：吉娃娃和藏獒都是狗,长得却比"吉娃娃与猫"差异更大。

早期(1960s–2000s)研究者手工设计特征来对抗这些变化(边缘检测算子、SIFT、HOG 等——曾是 CV 工程师的核心技能),精巧但天花板低。2012 年 AlexNet 用端到端学习一举超越所有手工特征,此后**特征全部交给网络自动学习**——第 2 章讲过的故事,正是发生在 CV 领域。

## 5.2 图像分类与 CNN 王朝

### 5.2.1 ImageNet：数据集驱动革命

**图像分类**（这张图是什么？）是 CV 的"果蝇"——最基础的实验任务。斯坦福李飞飞团队 2009 年发布 **ImageNet**：1400 万张标注图片、2 万+类别,并自 2010 年举办 ILSVRC 挑战赛（1000 类分类）。

这个数据集的战略意义怎么强调都不为过：**它第一次为深度模型提供了足够的"食物"**。2012 年 AlexNet 在此夺冠（错误率 26%→15%），2015 年 ResNet 达到 3.6%,首次超过人类水平（约 5%）。ImageNet 预训练权重成为整个 CV 界的通用起点——"预训练+微调"范式的发源地。

### 5.2.2 CNN 王朝的演进逻辑

第 2 章讲了卷积原理，这里看演进主线（每一代解决上一代的问题）：

| 模型 | 年份 | 核心贡献 | 解决的问题 |
|---|---|---|---|
| LeNet-5 | 1998 | 卷积+池化+全连接的基本配方 | 证明 CNN 可行(手写数字) |
| AlexNet | 2012 | ReLU、Dropout、GPU 训练、数据增强 | 深网络训不动、过拟合 |
| VGG | 2014 | 全部用 3×3 小核、深达 19 层 | 证明"深"是关键,结构规整化 |
| GoogLeNet | 2014 | Inception 多尺度并行卷积 | 计算效率 |
| **ResNet** | 2015 | **残差连接**,152 层+ | 深度退化/梯度消失,CV 史最重要单点突破 |
| MobileNet 等 | 2017+ | 深度可分离卷积等轻量化设计 | 手机端侧部署 |
| EfficientNet | 2019 | 复合缩放(深度/宽度/分辨率联合调) | 系统化的模型缩放 |

**规律**：更深 → 更稳（残差）→ 更省（轻量化）→ 更系统（自动缩放）。到 2020 年,CNN 已高度成熟,创新趋于饱和——恰在此时 Transformer 跨界而来（5.4 节）。

## 5.3 核心任务：从"是什么"到"在哪里、什么关系"

分类只回答"图里主要是什么"。实用系统需要更精细的理解,按粒度递进：

```
分类        →  这张图是"街景"
目标检测     →  图中有:行人(框1)、汽车(框2、框3)、红绿灯(框4)
语义分割     →  每个像素属于:道路/人行道/行人/车辆/天空...
实例分割     →  每个像素属于:行人甲/行人乙/3号车...(区分个体)
姿态估计     →  行人甲的头、肩、肘、膝关节点位置
深度估计     →  每个像素距相机多远
```

### 5.3.1 目标检测（Object Detection）

**任务**：找出图中所有目标,给出**类别 + 边界框**。自动驾驶、安防、工业质检的核心。

两条技术路线：

- **两阶段（精度优先）**：先提出"可能有东西"的候选区域,再逐个分类。代表 **R-CNN 系列**（R-CNN → Fast → Faster R-CNN）,演进逻辑是把流水线各环节逐步并入同一个网络端到端训练。
- **单阶段（速度优先）**：一次前向直接在密集网格上同时预测所有框和类别。代表 **YOLO**（You Only Look Once）系列——名字概括一切。YOLO 已迭代十余版,毫秒级推理,是工业部署的绝对主力。
- **Transformer 路线**：DETR（2020）把检测看作"集合预测",用注意力直接输出框集合,免去锚框/非极大值抑制等手工组件——延续"去人工设计"的历史方向。

### 5.3.2 图像分割（Segmentation）

**任务**：像素级分类。医学影像（勾画肿瘤边界）、自动驾驶（可行驶区域）、修图抠像的核心。

- 经典架构 **U-Net**（2015）：编码器逐步下采样提取语义,解码器逐步上采样恢复分辨率,同层之间用"跳跃连接"把细节直接传过去——U 形结构由此得名。因在小数据医学影像上表现出色而封神,**后来还意外成为扩散模型的骨干网络**（5.5 节）。
- **SAM**（Segment Anything Model, 2023, Meta）：分割领域的"大模型时刻"——1100 万图、11 亿掩码训练,可按点、框、文字提示分割**任何**物体,零样本泛化到新领域。标志 CV 也进入"基础模型"（foundation model）时代。

### 5.3.3 其他重要方向速览

- **人脸识别**：检测→对齐→特征嵌入（同人向量近,异人向量远——度量学习）。刷脸支付/门禁的原理,也是隐私争议核心（第 10 章）。
- **OCR 文字识别**：文档数字化、车牌识别;如今已被多模态大模型大幅整合。
- **视频理解**：动作识别、目标跟踪、时序定位——多了时间维度,算力需求陡增。
- **3D 视觉**：从图像恢复三维（深度估计、点云、NeRF/3D Gaussian Splatting 神经渲染）,机器人与自动驾驶的关键(与第 6 章具身智能衔接)。

## 5.4 Vision Transformer：CNN 的挑战者

### 5.4.1 ViT 的朴素方案

2020 年谷歌提出 **Vision Transformer（ViT）**,问题很直接:Transformer 吃的是 token 序列,图像怎么变序列?

**答案粗暴**：把图像切成 16×16 的小块（patch）,每块拉平线性映射成一个向量——**一个 patch 就是一个"视觉单词"**,然后原封不动地喂给标准 Transformer:

```
图像 224×224 → 切成 14×14=196 个 patch → 196 个 token → 标准 Transformer 编码器 → 分类
```

论文标题直言不讳:"An Image is Worth 16×16 Words"（一图值 16×16 个词）。

### 5.4.2 归纳偏置之战

ViT 抛弃了 CNN 的两大先验（局部性、平移不变性）,后果符合第 2 章的规律:

- **小数据**：ViT 输给 CNN——没有先验,学不出来。
- **大数据**（数亿图以上）：ViT 反超——数据足够时,模型自己学到的"注意力模式"比人工先验更优,且注意力可以第一层就建立全图联系（CNN 要堆很多层才能扩大感受野）。

**又一次"苦涩的教训"**。此后视觉架构走向融合:Swin Transformer 引入层次化+滑窗（借鉴 CNN 思想）,ConvNeXt 反向用 ViT 的训练配方现代化 CNN,两者性能咬得很紧。但 ViT 的真正胜负手不在分类精度,而在**统一性**:

- 与文本共享同一种架构 → 多模态融合天然顺畅（CLIP、GPT-4V,第 6 章)。
- Scaling 特性好 → 视觉大模型可复用 LLM 的全套规模化经验。
- **今天所有多模态大模型的视觉编码器几乎都是 ViT**。

### 5.4.3 视觉自监督：摆脱标注

ImageNet 的 1400 万标注是人海战术,不可持续。视觉自监督学习让模型从无标注图像学习:

- **对比学习**（SimCLR/MoCo, 2020）：同一张图两次随机增强(裁剪/变色)得到的版本应该"相认"(表示相近),不同图应该疏远。
- **掩码图像建模**（MAE, 2021）：遮住图像 75% 的 patch,让模型重建——BERT 完形填空的视觉版,训练又快又好。
- **DINO 系列**：自蒸馏方法,学出的特征无需微调即有惊人的语义结构(注意力图自动聚焦物体轮廓)。DINOv2 已成为通用视觉特征的事实标准之一。

至此 CV 与 NLP 的技术栈全面合流:**Transformer 架构 + 自监督预训练 + 大规模数据**。

## 5.5 生成式视觉：机器学会画画

理解图像之外,CV 的另一半是**生成**图像。这是近年最出圈的方向(Midjourney、Stable Diffusion)。

### 5.5.1 GAN：以假乱真的对抗游戏

**生成对抗网络（GAN, 2014, Goodfellow）**：两个网络对抗训练——

- **生成器**：从随机噪声生成假图,目标是骗过判别器。
- **判别器**：判断图片真假,目标是不被骗。

如同造假币者与验钞警察的军备竞赛,双方共同进化,最终生成器产出以假乱真的图像。GAN 统治图像生成七年(StyleGAN 的人脸生成、"这个人不存在"网站),但**训练不稳定**(两个网络的平衡极难维持)、生成多样性不足(模式坍缩),最终被扩散模型取代。"深度伪造"(Deepfake)一词也诞生于 GAN 时代。

### 5.5.2 扩散模型：从噪声中雕刻图像

**扩散模型（Diffusion Model）**是当前图像/视频生成的主流范式,思想优美：

```
前向过程(固定,不用学):  清晰图像 → 一步步加噪 → ... → 纯噪声
反向过程(学习目标):     纯噪声 → 一步步去噪 → ... → 清晰图像
```

训练时:给图片加已知强度的噪声,让网络（常用 U-Net 或 Transformer）**预测所加的噪声**——一个稳定的监督学习目标,完全没有 GAN 的对抗不稳定。生成时:从纯随机噪声出发,几十步迭代去噪,图像逐渐"显影"。类比米开朗基罗:"雕像本就在石头里,我只是去掉多余部分"——扩散模型在噪声里"看见"图像,逐步凿出来。

**文生图（Text-to-Image）**的完整配方(以 Stable Diffusion 为例)：

1. **文本编码器**(CLIP 文本塔,见第 6 章)把提示词变成语义向量;
2. **潜在扩散**:不在像素空间去噪(太贵),先用自编码器把图像压缩到小的潜在空间,在那里扩散——算力降百倍,消费级显卡可跑,开源后引爆创作生态;
3. **条件注入**:去噪的每一步都用交叉注意力"看着"文本向量,确保图像符合描述。

2022 年 DALL·E 2、Midjourney、Stable Diffusion 相继发布,"文生图元年";此后发展为文生视频(Sora 等,2024 起)——把图像 patch 扩展为时空 patch,用 DiT(Diffusion Transformer,扩散+Transformer 骨干)在海量视频上训练,生成分钟级连贯视频,甚至展现朴素的物理规律模拟能力(也仍会犯违反物理的错误——"视频生成模型是否是世界模型"是激烈争论中的前沿问题,第 7 章再谈)。

### 5.5.3 生成技术的另一面

生成能力带来真实的社会问题,在此点题、第 10 章展开:深度伪造(换脸诈骗、虚假新闻)、版权争议(训练数据未授权、画师风格被模仿)、内容真实性危机("有图有真相"时代终结)。技术对策包括生成内容水印、检测模型、内容溯源标准(C2PA)——但攻防不对称,检测始终落后于生成。

## 5.6 CV 的落地版图与现实挑战

### 5.6.1 主要应用场景

- **自动驾驶**：多摄像头+雷达融合感知,检测/分割/跟踪/预测全家桶,CV 最大规模的落地战场之一。纯视觉 vs 激光雷达融合的路线之争仍在继续。
- **医疗影像**：肺结节筛查、眼底病变、病理切片分析——在特定任务上达到专家水平,监管审批的 AI 医疗器械逐年增多。定位是辅助诊断而非替代医生。
- **工业质检**：流水线缺陷检测,7×24 不疲劳,替代大量枯燥目检岗位。
- **农业/遥感**：卫星影像分析、作物监测、灾害评估。
- **消费级**：手机计算摄影(夜景、人像虚化本质是 CV 算法)、AR 滤镜、相册搜索、扫码。

### 5.6.2 现实世界的硬骨头

- **长尾问题**：模型对常见场景表现好,对罕见情况(积雪覆盖的交通标志、奇装异服的行人)不可靠——而安全恰恰取决于罕见情况。自动驾驶"最后 1% 比前 99% 难"的根源。
- **域偏移**：训练数据与部署环境不一致(晴天数据→雨夜部署),性能悄然崩塌。
- **对抗样本**：对图像做人眼不可见的微扰,就能让模型把熊猫认成长臂猿;贴几张贴纸能让停车标志被认成限速牌——揭示深度视觉模型与人类视觉的机制性差异,也是安全隐患(第 10 章)。
- **标注成本与隐私**：像素级标注极贵;人脸等生物特征数据的采集与使用受严格监管(GDPR、中国个保法)。

## 5.7 本章小结

1. 图像对机器只是数字矩阵;视觉难在**语义鸿沟**与**万变的成像条件**,类内差异可大于类间差异(莫拉维克悖论的主场)。
2. **ImageNet+AlexNet(2012)** 终结手工特征时代;CNN 王朝十年演进的主线是**更深(残差)、更省(轻量化)、更系统(复合缩放)**,ResNet 是最重要的单点突破。
3. 核心任务按粒度递进:**分类→检测(YOLO/R-CNN)→分割(U-Net/SAM)**;演进方向是端到端化、去手工组件化、基础模型化(SAM 是 CV 的"大模型时刻")。
4. **ViT** 把图像切 patch 当序列,大数据下击败 CNN 先验——苦涩的教训重演;其真正意义是**与 NLP 架构统一**,成为一切多模态大模型的视觉入口。自监督(对比学习/MAE/DINO)使视觉摆脱标注依赖,CV 与 NLP 技术栈全面合流。
5. 生成式视觉:**GAN(对抗,已退位)→扩散模型(去噪,当前主流)**;潜在扩散+文本条件=文生图;时空 patch+DiT=文生视频。生成能力伴随深度伪造与版权的社会代价。
6. 落地的真正难关不是平均精度,而是**长尾、域偏移、对抗鲁棒性**——安全攸关场景中,罕见情况决定一切。

## 思考题

1. "类内差异大于类间差异"——用吉娃娃/藏獒/猫的例子说明它为什么让基于像素距离的朴素分类必然失败。
2. ResNet 之前,"网络越深反而训练误差越大"(退化问题)。这为什么不能用"过拟合"解释?残差连接如何化解?
3. YOLO(单阶段)和 Faster R-CNN(两阶段)分别适合什么场景?工业界为何偏爱前者?
4. ViT 在小数据集上不如 CNN、大数据上反超——用"归纳偏置"概念解释这条交叉曲线,并联系第 2 章"苦涩的教训"。
