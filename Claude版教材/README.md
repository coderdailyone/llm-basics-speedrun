## 阅读建议

- **主线**：1 → 2 → 3 → 4 是必读主干（通向大语言模型的直线路径），5 → 6 拓展到视觉与身体，7 → 10 是思辨与延伸。
- **速通**：只读每章的"本章小结 + 关键术语表"，约一小时可过完全书骨架。
- **深读**：认真做每章思考题——多数题目没有标准答案，它们是为讨论与检索准备的抓手。
